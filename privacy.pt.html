Política de Privacidade

Última atualização: 6 de setembro de 2026

Esta política de privacidade explica como o aplicativo móvel e para Android TV Tivi Ease Go ("Aplicativo") coleta, usa, armazena e protege os dados do usuário. Ao instalar e usar o Aplicativo, você concorda com esta política.

1. Dados que Coletamos

1.1. Informações da Conta (Firebase Authentication)

O Aplicativo usa o Firebase Authentication para criação de conta e login. As seguintes informações são coletadas:

  • Endereço de e-mail — para criação de conta e login
  • Senha — com hash pelo Firebase, nunca armazenada em texto simples
  • Nome de exibição — nome de perfil opcional

1.2. Identificador do Dispositivo

Para verificação de licença premium e gerenciamento de dispositivos:

  • ANDROID_ID — identificador do dispositivo fornecido pelo sistema Android (Settings.Secure.ANDROID_ID)
  • Este identificador é usado para rastrear quais dispositivos têm licenças premium ativas
  • Este identificador não é usado para fins de publicidade ou rastreamento

1.3. Informações de Compra (Google Play Billing)

Para verificar suas compras premium:

  • Token de compra — token de verificação de compra fornecido pelo Google Play
  • Data da compra e ID do produto
  • As informações são obtidas via Google Play Billing API e verificadas por meio do Firebase Cloud Functions

1.4. Informações de IPTV / Playlists

Para reproduzir suas playlists de IPTV:

  • URLs de servidor M3U/Xtream Codes e credenciais de login — inseridas pelo usuário
  • Listas de canais e dados de EPG (Electronic Program Guide) — obtidos do servidor de IPTV do usuário
  • Essas informações são usadas exclusivamente para acessar o próprio serviço de IPTV do usuário

1.5. Dados de Visualização (Somente no Dispositivo)

Os seguintes dados são armazenados apenas no seu dispositivo e não são enviados a servidores:

  • Progresso de visualização — posição de exibição de filmes/séries
  • Favoritos / Minha Lista — conteúdo marcado
  • Gravações — configurações de gravação
  • Ordenação de canais e canais ocultos
  • Configurações do reprodutor

1.6. Dados de Sincronização (Firebase Firestore)

Quando a sincronização da conta está ativada, os seguintes dados são enviados para o Firebase Firestore:

  • Favoritos, progresso de visualização, configurações de gravação
  • Configuração de playlists
  • Configurações de perfil

Esses dados estão vinculados exclusivamente à sua conta e não são compartilhados com outros usuários.

1.7. Consultas de Metadados (TMDB / OMDb)

Para enriquecer os metadados de filmes e séries (pôsteres, descrições, elenco):

  • Os títulos de filmes/séries são consultados nas APIs do TMDB (themoviedb.org) e OMDb
  • As imagens de pôster e de fundo são baixadas do TMDB CDN e armazenadas em cache no dispositivo
  • Essas consultas servem apenas para fins de enriquecimento de conteúdo

2. Dados que Não Coletamos

O Aplicativo não coleta nem processa os seguintes dados:

  • Identificadores de publicidade (GAID / AAID / IDFA)
  • Números de identificação pessoal (documento de identidade nacional, passaporte, endereço)
  • Dados de localização (GPS)
  • Contatos / agenda de endereços
  • SMS ou histórico de chamadas
  • Histórico de navegação
  • Galeria de fotos ou acesso à câmera
  • Acesso ao microfone (exceto para pesquisa por voz, somente quando iniciada pelo usuário)

4. Armazenamento e Segurança de Dados

4.1. Armazenamento Local (no Dispositivo)

  • O progresso de visualização, os favoritos e as configurações são armazenados no dispositivo usando SharedPreferences
  • Pôsteres e logotipos de canais são armazenados em cache no diretório temporário (máx. 150 MB)
  • As gravações são armazenadas no armazenamento do dispositivo

4.2. Armazenamento em Nuvem (Firebase)

  • Os dados de autenticação são gerenciados pelo Firebase Authentication
  • Os dados de sincronização são armazenados no Firebase Firestore
  • As informações de licença premium são armazenadas no Firebase Firestore
  • Toda a comunicação com a nuvem é criptografada via HTTPS/TLS

4.3. Medidas de Segurança

  • As senhas nunca são armazenadas em texto simples — o Firebase Authentication cuida do hash
  • Detecção de root e verificação de assinatura do APK para verificações de segurança
  • Toda a comunicação de rede é criptografada via SSL/TLS
  • As credenciais do servidor de IPTV são armazenadas localmente no dispositivo e não são compartilhadas com terceiros

5. Serviços de Terceiros

5.1. Firebase (Google LLC)

  • Finalidade: Autenticação, sincronização em nuvem, Cloud Functions
  • Dados: E-mail, hash de senha, dados de sincronização, identificador do dispositivo
  • Política: Política de Privacidade do Firebase

5.2. Google Play Billing

  • Finalidade: Processamento de compras premium
  • Dados: Token de compra, ID do produto
  • Política: Política de Privacidade do Google

5.3. TMDB (The Movie Database)

  • Finalidade: Fornecimento de metadados e pôsteres de filmes/séries
  • Dados: Consultas de títulos de filmes/séries (incluindo endereço IP)
  • Política: Política de Privacidade do TMDB

5.4. OMDb API

  • Finalidade: Fornecimento de metadados de filmes/séries
  • Dados: Consultas de títulos de filmes/séries
  • Política: Política de Privacidade do OMDb

6. Privacidade de Crianças

O Aplicativo não é direcionado a crianças menores de 13 anos. Não coletamos conscientemente dados pessoais de crianças menores de 13 anos. Se você tomar conhecimento de que uma criança menor de 13 anos nos forneceu dados pessoais, entre em contato conosco e excluiremos imediatamente esses dados.

7. Exclusão de Dados

As seguintes opções de exclusão estão disponíveis no Aplicativo:

  • Excluir Conta: Configurações → Conta → Excluir Conta — todos os seus dados na nuvem são excluídos permanentemente
  • Sair: Você pode sair da sua conta; os dados locais permanecem no dispositivo
  • Limpar Cache: Configurações → Armazenamento — o cache de pôsteres/logotipos pode ser limpo
  • Exportação de Dados: Você pode visualizar seus dados de sincronização na sua conta

Todas as solicitações de exclusão são processadas em até 30 dias.

8. Conformidade com GDPR e KVKK

De acordo com o Regulamento Geral sobre a Proteção de Dados da UE (GDPR) e a Lei Turca de Proteção de Dados Pessoais (KVKK), você tem os seguintes direitos:

  • Acesso aos seus dados
  • Retificação dos seus dados
  • Eliminação dos seus dados ("direito a ser esquecido")
  • Limitação do tratamento
  • Portabilidade dos dados
  • Oposição ao tratamento

Para exercer esses direitos, entre em contato conosco pelo e-mail tivieasego@gmail.com.

9. Cookies e Publicidade

O Aplicativo não usa cookies. Não há anúncios no Aplicativo. Ele não contém SDKs de publicidade de terceiros.

10. Notificação de Violação de Dados

Em caso de violação de dados, as autoridades competentes e os usuários serão notificados em até 72 horas.

Esta política de privacidade pode ser atualizada periodicamente. Em caso de alterações significativas, você será notificado por notificação no aplicativo ou por e-mail. A data da última atualização da política está indicada no topo desta página.
