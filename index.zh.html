电视指南——每个频道的节目一目了然。

观看所需的一切

只需添加播放列表并拿起遥控器——其余交给 TiviEase Go。

M3U 与 Xtream Codes

通过 URL、本地文件或 Xtream 账户（服务器 + 用户名 + 密码）添加播放列表。直播、电影、剧集自动分类。

自动语言与字幕检测

在多音轨和字幕内容中自动找到您的首选语言 — 每个标题都会自动选择正确的音轨和字幕，无需手动设置。

EPG 指南

来自 XMLTV 源的各频道节目表。自动/手动匹配、时移、过往日期支持。

录制与提醒

在 EPG 中长按节目即可创建录制计划或提醒。接收通知，或频道自动打开。

多屏播放（PIP）

最多同时并排观看 4 个频道。均分视图、大屏模式、每个频道独立控制。

个人资料与家长控制

每个人的个人资料：独立的收藏、历史记录和设置。PIN 锁定、年龄限制、频道隐藏保护儿童。

下载与离线

下载电影和剧集离线观看。可录制和下载到 SMB 网络文件夹。

手机变遥控器

将手机变成电视遥控器：方向键、数字键、彩色按钮、键盘——尽在其中。

DLNA 与投屏

向网络上的 DLNA 设备推流，或将手机内容发送到电视。

支持 TMDB 与 OMDb

使用您自己的免费 API 密钥获取海报、简介、演员阵容和 IMDb 评分。智能缓存加快加载。

4 步开始观看

打开应用

首次启动会显示欢迎屏幕：选择「添加播放列表」卡片。

添加播放列表

M3U：输入 URL 或文件；Xtream：服务器 + 用户名 + 密码。

添加 EPG

在设置 › 电视指南 ›「添加 EPG 源」中输入 XMLTV 地址；频道自动匹配。

开始观看

在顶部菜单选择电视并点击频道——播放将以全屏开始。
