Integritetspolicy

Senast uppdaterad: 6 september 2026

Denna integritetspolicy förklarar hur mobil- och Android TV-appen Tivi Ease Go ("Appen") samlar in, använder, lagrar och skyddar användardata. Genom att installera och använda Appen godkänner du denna policy.

1. Data vi samlar in

1.1. Kontoinformation (Firebase Authentication)

Appen använder Firebase Authentication för att skapa konto och logga in. Följande information samlas in:

  • E-postadress — för att skapa konto och logga in
  • Lösenord — hashas av Firebase, lagras aldrig i klartext
  • Visningsnamn — valfritt profilnamn

1.2. Enhetsidentifierare

För verifiering av premiumlicens och enhetshantering:

  • ANDROID_ID — enhetsidentifierare som tillhandahålls av Android-systemet (Settings.Secure.ANDROID_ID)
  • Denna identifierare används för att spåra vilka enheter som har aktiva premiumlicenser
  • Denna identifierare används inte för annonserings- eller spårningsändamål

1.3. Köpinformation (Google Play Billing)

För att verifiera dina premiumköp:

  • Köptoken — verifieringstoken för köp som tillhandahålls av Google Play
  • Köpdatum och produkt-ID
  • Information hämtas via Google Play Billing API och verifieras via Firebase Cloud Functions

1.4. IPTV- / spellisteinformation

För att spela upp dina IPTV-spellistor:

  • M3U/Xtream Codes-serveradresser och inloggningsuppgifter — anges av användaren
  • Kanallistor och EPG-data (elektronisk programguide) — hämtas från användarens IPTV-server
  • Denna information används uteslutande för att få åtkomst till användarens egen IPTV-tjänst

1.5. Visningsdata (endast på enheten)

Följande data lagras endast på din enhet och skickas inte till servrar:

  • Tittarframsteg — visningsposition för filmer/serier
  • Favoriter / Min lista — markerat innehåll
  • Inspelningar — inspelningsinställningar
  • Kanalordning och dolda kanaler
  • Spelarinställningar

1.6. Synkroniseringsdata (Firebase Firestore)

När kontosynkronisering är aktiverad laddas följande data upp till Firebase Firestore:

  • Favoriter, tittarframsteg, inspelningsinställningar
  • Spellistekonfiguration
  • Profilinställningar

Denna data är uteslutande kopplad till ditt konto och delas inte med andra användare.

1.7. Metadataförfrågningar (TMDB / OMDb)

För att berika metadata för filmer och serier (affischer, beskrivningar, rollista):

  • Filmtitlar/serietitlar efterfrågas via TMDB (themoviedb.org) och OMDb API:er
  • Affischer och bakgrundsbilder laddas ner från TMDB CDN och cachas på enheten
  • Dessa förfrågningar används endast för att berika innehåll

2. Data vi inte samlar in

Appen samlar inte in eller behandlar följande data:

  • Annonsidentifierare (GAID / AAID / IDFA)
  • Personliga identifikationsnummer (nationellt ID, pass, adress)
  • Platsdata (GPS)
  • Kontakter / adressbok
  • SMS eller samtalshistorik
  • Webbläsarhistorik
  • Fotogalleri eller kameraåtkomst
  • Mikrofonåtkomst (förutom röstsökning, endast när användaren startar den)

4. Datalagring och säkerhet

4.1. Lokal lagring (på enheten)

  • Tittarframsteg, favoriter och inställningar lagras på enheten med SharedPreferences
  • Affischer och kanallogotyper cachas i den tillfälliga katalogen (max 150 MB)
  • Inspelningar lagras i enhetens lagring

4.2. Molnlagring (Firebase)

  • Autentiseringsdata hanteras av Firebase Authentication
  • Synkroniseringsdata lagras i Firebase Firestore
  • Premiumlicensinformation lagras i Firebase Firestore
  • All molnskommunikation krypteras via HTTPS/TLS

4.3. Säkerhetsåtgärder

  • Lösenord lagras aldrig i klartext — Firebase Authentication hanterar hashningen
  • Root-detektering och APK-signaturverifiering för säkerhetskontroller
  • All nätverkskommunikation krypteras via SSL/TLS
  • IPTV-serveruppgifter lagras lokalt på enheten och delas inte med tredje part

5. Tredjepartstjänster

5.1. Firebase (Google LLC)

  • Ändamål: Autentisering, molnsynkronisering, Cloud Functions
  • Data: E-post, lösenordshash, synkroniseringsdata, enhetsidentifierare
  • Policy: Firebase integritetspolicy

5.2. Google Play Billing

  • Ändamål: Behandling av premiumköp
  • Data: Köptoken, produkt-ID
  • Policy: Googles integritetspolicy

5.3. TMDB (The Movie Database)

  • Ändamål: Tillhandahållande av metadata och affischer för filmer/serier
  • Data: Förfrågningar om filmtitlar/serietitlar (inklusive IP-adress)
  • Policy: TMDB:s integritetspolicy

5.4. OMDb API

  • Ändamål: Tillhandahållande av metadata för filmer/serier
  • Data: Förfrågningar om filmtitlar/serietitlar
  • Policy: OMDb:s integritetspolicy

6. Barns integritet

Appen riktar sig inte till barn under 13 år. Vi samlar inte medvetet in personuppgifter från barn under 13 år. Om du får kännedom om att ett barn under 13 år har lämnat personuppgifter till oss, kontakta oss så raderar vi omedelbart sådana uppgifter.

7. Radering av data

Följande raderingsalternativ finns tillgängliga i Appen:

  • Radera konto: Inställningar → Konto → Radera konto — all din molndata raderas permanent
  • Logga ut: Du kan logga ut från ditt konto; lokal data finns kvar på enheten
  • Rensa cache: Inställningar → Lagring — cachen för affischer/logotyper kan rensas
  • Dataexport: Du kan visa din synkroniseringsdata från ditt konto

Alla raderingsförfrågningar behandlas inom 30 dagar.

8. GDPR- och KVKK-efterlevnad

Enligt EU:s allmänna dataskyddsförordning (GDPR) och den turkiska lagen om skydd av personuppgifter (KVKK) har du följande rättigheter:

  • Tillgång till dina data
  • Rättelse av dina data
  • Radering av dina data ("rätten att bli glömd")
  • Begränsning av behandling
  • Dataportabilitet
  • Invändning mot behandling

För att utöva dessa rättigheter, kontakta oss på tivieasego@gmail.com.

9. Cookies och annonsering

Appen använder inte cookies. Det finns inga annonser i Appen. Den innehåller inga tredjeparts annons-SDK:er.

10. Anmälan om dataintrång

Vid ett dataintrång kommer relevanta myndigheter och användare att underrättas inom 72 timmar.

11. Policyändringar

Denna integritetspolicy kan uppdateras då och då. Vid väsentliga ändringar kommer du att meddelas via en notis i appen eller via e-post. Datumet för policyns senaste uppdatering anges högst upp på denna sida.
