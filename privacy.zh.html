隐私政策

最后更新：2026年9月6日

本隐私政策说明 Tivi Ease Go（"本应用"）移动和 Android TV 应用如何收集、使用、存储和保护用户数据。安装并使用本应用即表示您同意本政策。

1. 我们收集的数据

1.1. 账户信息（Firebase Authentication）

本应用使用 Firebase Authentication 进行账户创建和登录。收集以下信息：

  • 电子邮件地址 — 用于账户创建和登录
  • 密码 — 由 Firebase 进行哈希处理，绝不明文存储
  • 显示名称 — 可选的个人资料名称

1.2. 设备标识符

用于高级版许可证验证和设备管理：

  • ANDROID_ID — Android 系统提供的设备标识符（Settings.Secure.ANDROID_ID）
  • 此标识符用于跟踪哪些设备拥有有效的高级版许可证
  • 此标识符不用于广告或跟踪目的

1.3. 购买信息（Google Play Billing）

为验证您的高级版购买：

  • 购买令牌 — Google Play 提供的购买验证令牌
  • 购买日期和产品 ID
  • 信息通过 Google Play Billing API 获取，并通过 Firebase Cloud Functions 验证

1.4. IPTV / 播放列表信息

为播放您的 IPTV 播放列表：

  • M3U/Xtream Codes 服务器 URL 和登录凭据 — 由用户输入
  • 频道列表和 EPG（电子节目指南）数据 — 从用户的 IPTV 服务器获取
  • 此信息仅用于访问用户自己的 IPTV 服务

1.5. 观看数据（仅设备本地）

以下数据仅存储在您的设备上，不会发送到服务器：

  • 观看进度 — 电影/剧集的观看位置
  • 收藏 / 我的列表 — 标记的内容
  • 录制 — 录制设置
  • 频道排序和隐藏频道
  • 播放器设置

1.6. 同步数据（Firebase Firestore）

启用账户同步后，以下数据将上传至 Firebase Firestore：

  • 收藏、观看进度、录制设置
  • 播放列表配置
  • 个人资料设置

此数据仅与您的账户关联，不会与其他用户共享。

1.7. 元数据查询（TMDB / OMDb）

为丰富电影和剧集元数据（海报、简介、演员阵容）：

  • 电影/剧集标题会查询 TMDB（themoviedb.org）和 OMDb API
  • 海报和背景图从 TMDB CDN 下载并在设备本地缓存
  • 这些查询仅用于内容丰富目的

2. 我们不收集的数据

本应用不收集或处理以下数据：

  • 广告标识符（GAID / AAID / IDFA）
  • 个人身份识别号码（国民身份证、护照、地址）
  • 位置数据（GPS）
  • 联系人 / 通讯录
  • 短信或通话记录
  • 浏览器历史记录
  • 照片库或相机访问
  • 麦克风访问（语音搜索除外，仅在用户主动发起时）

3. 数据使用目的

数据目的
电子邮件和密码账户身份验证
设备标识符许可证验证和设备管理
购买令牌高级版购买验证
IPTV 服务器凭据访问用户自己的 IPTV 内容
观看数据用户体验（设备本地或同步）
电影/剧集标题TMDB/OMDb 元数据丰富

4. 数据存储与安全

4.1. 本地存储（设备上）

  • 观看进度、收藏和设置使用 SharedPreferences 存储在设备上
  • 海报和频道徽标缓存于临时目录（最大 150 MB）
  • 录制内容存储在设备存储中

4.2. 云存储（Firebase）

  • 身份验证数据由 Firebase Authentication 管理
  • 同步数据存储在 Firebase Firestore 中
  • 高级版许可证信息存储在 Firebase Firestore 中
  • 所有云通信均通过 HTTPS/TLS 加密

4.3. 安全措施

  • 密码绝不明文存储 — Firebase Authentication 负责哈希处理
  • 使用 Root 检测和 APK 签名验证进行安全检查
  • 所有网络通信均通过 SSL/TLS 加密
  • IPTV 服务器凭据存储在设备本地，不与第三方共享

5. 第三方服务

5.1. Firebase (Google LLC)

  • 目的：身份验证、云同步、Cloud Functions
  • 数据：电子邮件、密码哈希、同步数据、设备标识符
  • 政策：Firebase 隐私政策

5.2. Google Play Billing

  • 目的：高级版购买处理
  • 数据：购买令牌、产品 ID
  • 政策：Google 隐私政策

5.3. TMDB (The Movie Database)

  • 目的：电影/剧集元数据和海报提供
  • 数据：电影/剧集标题查询（包括 IP 地址）
  • 政策：TMDB 隐私政策

5.4. OMDb API

  • 目的：电影/剧集元数据提供
  • 数据：电影/剧集标题查询
  • 政策：OMDb 隐私政策

6. 儿童隐私

本应用不面向 13 岁以下儿童。我们不会故意收集 13 岁以下儿童的个人数据。如果您发现有 13 岁以下儿童向我们提供了个人数据，请联系我们，我们将立即删除此类数据。

7. 数据删除

应用内提供以下删除选项：

  • 删除账户：设置 → 账户 → 删除账户 — 您的所有云数据将被永久删除
  • 退出登录：您可以退出账户；本地数据保留在设备上
  • 清除缓存：设置 → 存储 — 可清除海报/徽标缓存
  • 数据导出：您可以从账户中查看同步数据

所有删除请求将在 30 天内处理。

  • 访问您的数据
  • 更正您的数据
  • 删除您的数据（"被遗忘权"）
  • 限制处理
  • 数据可携带性
  • 反对处理

要行使这些权利，请通过 tivieasego@gmail.com 联系我们。

本应用不使用 Cookie。应用内没有广告。不包含第三方广告 SDK。

10. 数据泄露通知

如发生数据泄露，我们将在 72 小时内通知相关主管部门和用户。
