Политика конфиденциальности

Последнее обновление: 6 сентября 2026 г.

Настоящая политика конфиденциальности объясняет, как мобильное приложение и приложение для Android TV Tivi Ease Go («Приложение») собирает, использует, хранит и защищает данные пользователей. Устанавливая и используя Приложение, вы соглашаетесь с настоящей политикой.

1. Какие данные мы собираем

1.1. Данные учётной записи (Firebase Authentication)

Приложение использует Firebase Authentication для создания учётной записи и входа. Собирается следующая информация:

  • Адрес электронной почты — для создания учётной записи и входа
  • Пароль — хешируется Firebase, никогда не хранится в открытом виде
  • Отображаемое имя — необязательное имя профиля

1.2. Идентификатор устройства

Для проверки премиум-лицензии и управления устройствами:

  • ANDROID_ID — идентификатор устройства, предоставляемый системой Android (Settings.Secure.ANDROID_ID)
  • Этот идентификатор используется для отслеживания устройств с активными премиум-лицензиями
  • Этот идентификатор не используется в рекламных целях или для отслеживания

1.3. Информация о покупках (Google Play Billing)

Для проверки ваших премиум-покупок:

  • Токен покупки — токен подтверждения покупки, предоставляемый Google Play
  • Дата покупки и идентификатор продукта
  • Информация получается через Google Play Billing API и проверяется с помощью Firebase Cloud Functions

1.4. Информация об IPTV / плейлистах

Для воспроизведения ваших IPTV-плейлистов:

  • URL-адреса серверов M3U/Xtream Codes и данные для входа — вводятся пользователем
  • Списки каналов и данные EPG (электронного телегида) — загружаются с IPTV-сервера пользователя
  • Эта информация используется исключительно для доступа к собственному IPTV-сервису пользователя

1.5. Данные просмотра (только на устройстве)

Следующие данные хранятся только на вашем устройстве и не отправляются на серверы:

  • Прогресс просмотра — позиция просмотра фильмов/сериалов
  • Избранное / Мой список — отмеченный контент
  • Записи — настройки записи
  • Порядок каналов и скрытые каналы
  • Настройки плеера

1.6. Данные синхронизации (Firebase Firestore)

При включённой синхронизации учётной записи в Firebase Firestore загружаются следующие данные:

  • Избранное, прогресс просмотра, настройки записи
  • Конфигурация плейлиста
  • Настройки профиля

Эти данные привязаны исключительно к вашей учётной записи и не передаются другим пользователям.

1.7. Запросы метаданных (TMDB / OMDb)

Для обогащения метаданных фильмов и сериалов (постеры, описания, актёрский состав):

  • Названия фильмов/сериалов запрашиваются через API TMDB (themoviedb.org) и OMDb
  • Постеры и фоновые изображения загружаются с CDN TMDB и кешируются на устройстве
  • Эти запросы используются только для обогащения контента

2. Данные, которые мы не собираем

Приложение не собирает и не обрабатывает следующие данные:

  • Рекламные идентификаторы (GAID / AAID / IDFA)
  • Персональные идентификационные номера (национальный ID, паспорт, адрес)
  • Данные о местоположении (GPS)
  • Контакты / адресная книга
  • SMS или история звонков
  • История браузера
  • Фотогалерея или доступ к камере
  • Доступ к микрофону (кроме голосового поиска, только по инициативе пользователя)

4. Хранение и защита данных

4.1. Локальное хранилище (на устройстве)

  • Прогресс просмотра, избранное и настройки хранятся на устройстве с использованием SharedPreferences
  • Постеры и логотипы каналов кешируются во временном каталоге (макс. 150 МБ)
  • Записи хранятся в памяти устройства

4.2. Облачное хранилище (Firebase)

  • Данные аутентификации управляются Firebase Authentication
  • Данные синхронизации хранятся в Firebase Firestore
  • Информация о премиум-лицензии хранится в Firebase Firestore
  • Все облачные соединения шифруются по HTTPS/TLS

4.3. Меры безопасности

  • Пароли никогда не хранятся в открытом виде — хеширование выполняет Firebase Authentication
  • Обнаружение root-доступа и проверка подписи APK для контроля безопасности
  • Все сетевые соединения шифруются по SSL/TLS
  • Данные доступа к IPTV-серверу хранятся локально на устройстве и не передаются третьим лицам

5. Сторонние сервисы

5.1. Firebase (Google LLC)

  • Цель: Аутентификация, облачная синхронизация, Cloud Functions
  • Данные: Электронная почта, хеш пароля, данные синхронизации, идентификатор устройства
  • Политика: Политика конфиденциальности Firebase

5.2. Google Play Billing

  • Цель: Обработка премиум-покупок
  • Данные: Токен покупки, идентификатор продукта
  • Политика: Политика конфиденциальности Google

5.3. TMDB (The Movie Database)

  • Цель: Предоставление метаданных и постеров фильмов/сериалов
  • Данные: Запросы названий фильмов/сериалов (включая IP-адрес)
  • Политика: Политика конфиденциальности TMDB

5.4. OMDb API

  • Цель: Предоставление метаданных фильмов/сериалов
  • Данные: Запросы названий фильмов/сериалов
  • Политика: Политика конфиденциальности OMDb

6. Конфиденциальность детей

Приложение не предназначено для детей младше 13 лет. Мы сознательно не собираем персональные данные детей младше 13 лет. Если вам станет известно, что ребёнок младше 13 лет предоставил нам персональные данные, свяжитесь с нами, и мы незамедлительно удалим такие данные.

7. Удаление данных

В Приложении доступны следующие варианты удаления:

  • Удаление учётной записи: Настройки → Учётная запись → Удалить учётную запись — все ваши облачные данные удаляются безвозвратно
  • Выход из учётной записи: Вы можете выйти из учётной записи; локальные данные останутся на устройстве
  • Очистка кеша: Настройки → Хранилище — можно очистить кеш постеров/логотипов
  • Экспорт данных: Вы можете просматривать данные синхронизации в своей учётной записи

Все запросы на удаление обрабатываются в течение 30 дней.
