Pour commencer

TiviEase Go fonctionne à la fois sur Android TV et téléphone/tablette avec une seule app. L'application ne fournit ni chaînes ni contenu — vous ajoutez la liste M3U ou le compte Xtream Codes de votre propre fournisseur IPTV.

Écran de premier lancement

Si aucune liste n'est définie à l'ouverture, l'écran d'accueil s'affiche. Il propose quatre cartes :

CarteQue fait-elle ?
Ajouter une liste

Connexion Google
Synchronisation cloud		Vous connecte avec votre compte Google ; vos sources, favoris et historique cloud sont téléchargés puis les listes se mettent à jour automatiquement.
Connexion par QR code

Astuce : si vous utilisez déjà TiviEase Go sur un autre appareil, le plus rapide est Connexion Google ou Connexion par QR code — toutes vos listes et réglages arrivent automatiquement.

Choix du profil

Si plusieurs profils existent sur l'appareil, l'écran « Choisir un profil » s'affiche au démarrage. Flèches + OK pour choisir. Les profils avec PIN la demandent d'abord. Chaque profil conserve ses propres favoris, contenus « Ma Liste », historique et réglages personnels.

  • Ajouter/modifier des profils : Réglages › Profils (voir Gestion des profils).
  • Changer de profil en cours : touchez l'icône avatar de la barre supérieure.

Connexion par QR code TV MOBILE

Utilisez votre téléphone au lieu de taper les identifiants sur la TV :

  1. Sur la TV, ouvrez la carte Connexion par QR code (écran d'accueil ou Réglages › Comptes) — un QR code apparaît. Il est valable 3 minutes.
  2. Sur le téléphone, ouvrez l'app TiviEase Go et scannez le code TV avec l'écran scanner QR.
  3. Touchez « Se connecter » sur le téléphone — « Validé — la TV se connecte » s'affiche.
  4. La TV se connecte en quelques secondes avec le compte du téléphone ; liste et réglages se synchronisent.

Si le QR code expire, fermez la boîte et rouvrez-la — un nouveau code est généré. La connexion QR exige la même app ouverte sur le téléphone avec votre compte déjà connecté.

Connexion Google et synchronisation

En vous connectant avec un compte Google, ces données se synchronisent entre appareils : réglages des sources/listes, favoris, « Ma Liste », historique, profils et licence premium. Après la première connexion, vos sources et l'EPG se téléchargent automatiquement — pas de mise à jour manuelle.

  • Réglages de sync et appareils liés : Réglages › Comptes, Sync & Appareils.
  • L'app fonctionne aussi sans compte — les données restent alors sur l'appareil.

Ajouter une liste de lecture

Deux types de sources sont pris en charge : M3U (URL ou fichier local) et Xtream Codes (serveur + identifiants). À l'ajout, le contenu est classé automatiquement en TV en direct / Films / Séries.

Où l'ajouter ?

  • Depuis la carte Ajouter une liste de l'écran d'accueil,
  • ou via Réglages › Listes de lecture › Ajouter une liste.

Ajouter une liste M3U

  1. Ouvrez Ajouter une liste, choisissez la carte M3U / XMLTV.
  2. Dans Nom, donnez un nom à la liste (ex. « Liste principale »).
  3. Dans URL / Chemin du fichier, saisissez le lien M3U ou choisissez un fichier avec l'icône dossier. Extensions prises en charge : .m3u, .m3u8, .xml, .txt.
  4. Touchez Ajouter — la liste est téléchargée et traitée ; la progression s'affiche sur la barre de chargement en bas.

Lors du choix d'un fichier, le nom du fichier est utilisé automatiquement si le champ nom est vide. Les URL doivent commencer par http/https.

Ajouter un compte Xtream Codes

  1. Choisissez la carte Xtream.
  2. Nom de la source : le nom de votre choix (ex. « Xtream principal »).
  3. URL du serveur : l'adresse de votre fournisseur, ex. http://serveur.com:8080
  4. Identifiant et Mot de passe : les identifiants de votre fournisseur. L'icône œil du champ mot de passe permet de voir la saisie.
  5. Ajouter — l'app se connecte à l'API Xtream ; directs, films et séries sont chargés séparément.

En version gratuite, 1 liste au total peut être ajoutée (M3U ou Xtream — pas les deux). Listes illimitées : Pro.

Ajouter une source EPG (XMLTV)

Pour le guide des programmes, ajoutez l'adresse XMLTV/EPG de votre fournisseur IPTV :

  1. Ouvrez Réglages › Guide TV › Ajouter une source EPG.
  2. Saisissez un nom et l'URL / Adresse, puis enregistrez.
  3. Après téléchargement, les chaînes sont associées automatiquement par similarité de nom ; associez les restantes manuellement via Association EPG des chaînes.

La version gratuite permet 1 source EPG. Certains fournisseurs Xtream servent leur propre EPG — à l'ajout d'une source Xtream, l'EPG arrive souvent automatiquement.

Groupes, tri et filtres de noms

  • Groupes de chaînes : gèrent les en-têtes de groupes venant du M3U/Xtream. Les groupes masqués n'apparaissent pas dans la liste TV ; le tri définit l'ordre des groupes.
  • Tri : avec « Tri manuel » vous créez votre propre ordre dans la liste des chaînes ; « Ordre d'origine » conserve l'ordre du fichier.
  • Filtres de noms : retirent les motifs au début/fin des noms de chaînes (ex. préfixes de pays) — la liste devient plus lisible. Filtre distinct pour les noms VOD : Réglages › Infos médias › Filtres de noms VOD.

Utiliser le Guide TV (EPG)

Le menu TV bascule entre deux vues : liste des chaînes et grille EPG (« Passer à la liste EPG » / « Passer à la liste des chaînes »).

  • Colonne gauche : logos et noms des chaînes. ▲▼ changent de chaîne ; ses programmes s'affichent à droite.
  • Grille droite : frise horaire — cartes de programmes avec leur durée. ◀▶ avancent dans le temps.
  • Choix du jour : avec Hier / Aujourd'hui / Demain et les flèches « jour précédent / suivant », remontez aussi loin que le permet le réglage Données EPG passées.
  • Appui long OK sur une ligne de chaîne : ouvre le menu contextuel EPG (favori, enregistrement, rappel, masquage…).
  • Appui court OK sur une chaîne : la regarde en plein écran.

Pas d'EPG sur une chaîne ? Vérifiez d'abord qu'une source EPG est définie et à jour (Réglages › Guide TV › Mettre à jour l'EPG), puis associez la chaîne manuellement avec « Associer l'EPG ».

Recherche & recherche vocale

  • Le menu Recherche (ou « Recherche » des menus contextuels) ouvre la recherche intelligente. Elle interroge ensemble films, séries, noms de chaînes et programmes EPG (« Correspondances programmes », « Diffusions TV »).
  • L'icône micro lance la Recherche vocale — parlez pendant « J'écoute… » ; la permission micro est demandée à la première utilisation.
  • L'Historique de recherche liste les recherches passées ; « Effacer » le vide.
  • Sur mobile, l'onglet recherche remplit le même rôle ; saisie tactile.

Multi-écran (PIP)

Avec PIP de la carte ou la fonction multi-écran, plusieurs chaînes jouent en même temps (jusqu'à 4 écrans). Options du menu multi-écran :

  • Ajouter / fermer un écran : ouvre une nouvelle cellule de flux ou ferme celle choisie.
  • Vue égale / Grand écran : partage les écrans équitablement ou en agrandit un.
  • Changer de chaîne : change la chaîne de la cellule ayant le focus.
  • Plein écran / Retour aux écrans / Écran unique : agrandit une cellule ou revient à la vue multiple.
  • Lecture/Pause, Couper/activer le son, Recharger : lecture et son par cellule (le son vient d'un seul écran à la fois).

Le multi-écran sollicite le processeur ; sur les TV modestes, 2 écrans sont recommandés.

Enregistrement & Rappels PRO

Enregistrement de programmes

  1. Dans l'EPG, appui long OK sur la ligne de chaîne du programme à enregistrer.
  2. Enregistrer : ajoute le programme à la liste d'enregistrements avec les minutes supplémentaires des réglages. Sans programme, un enregistrement manuel de 2 h est planifié dès maintenant.
  3. Enregistrement personnalisé : ouvre une boîte pour choisir les minutes supplémentaires début/fin (0/+1/+5/+10 min) avant de créer l'enregistrement.
  4. À l'heure dite, l'enregistrement démarre automatiquement ; un symbole REC clignotant apparaît sur la carte du programme dans le flux.

Temps avant / après l'enregistrementTemps supplémentaire ajouté au début et à la fin de chaque enregistrement : 0, 1, 5 ou 10 minutes. Évite de rater le début/la fin si le programme démarre tard ou déborde.

Rappels

  • Programmez un rappel via Ajouter un rappel du menu contextuel EPG ; rechoisissez-le pour le retirer.
  • Moment du rappel : 1, 2, 5 ou 10 minutes avant le début du programme.
  • Réglages › Rappels : options de notification et « Ouvrir la chaîne automatiquement » (la TV bascule seule sur la chaîne à l'heure prévue) ; la liste complète des rappels se gère aussi ici.

Guide des réglages

L'écran des réglages comporte trois colonnes : colonne gauche 13 catégories, colonne centrale éléments de la catégorie, colonne droite panneau de description/réglage de l'élément choisi. L'icône loupe du titre ouvre une fenêtre de recherche dans les réglages. Chaîne+/− sautent 10 lignes dans la liste des catégories.

En version gratuite, certaines catégories sont verrouillées (badge cadenas) : Lecteur, Apparence, Infos médias, Enregistrement, Rappels, Profils, Contrôle parental, Téléchargements et Autre. Une catégorie verrouillée ouvre le panneau de passage à Pro.

Dépannage & FAQ

Les chaînes n'arrivent pas / la liste ne se charge pas

Vérifiez que l'URL est correcte et commence par http(s)://. Dans Réglages › Listes de lecture › Listes existantes, sélectionnez la source et retéléchargez avec « rafraîchir » ; sur Xtream, vérifiez l'absence d'espaces dans l'identifiant/le mot de passe. Contrôlez la connexion Internet et que le fournisseur est en ligne.

L'EPG (guide des programmes) est vide

Ajoutez d'abord une source XMLTV via Réglages › Guide TV › Ajouter une source EPG et téléchargez-la avec Mettre à jour l'EPG. Si une chaîne reste sans données, choisissez le bon canal EPG manuellement via Associer l'EPG du menu contextuel. Horaires décalés ? Corrigez avec Décalage horaire.

Le flux ne s'ouvre pas ou se fige

Mettez la Mise en mémoire tampon sur « Moyen/Grand » dans Réglages › Lecteur ; si le problème persiste, essayez le décodeur logiciel dans Sortie vidéo. Les flux 4K fatiguent les TV modestes — préférez la version HD/FHD de la chaîne.

Pas de son ou son/image désynchronisés

Essayez de désactiver le Passthrough audio dans Réglages › Lecteur › Sortie audio (le bitstream pose problème sur certains appareils). Pour le décalage, utilisez le curseur Décalage audio ; si le flux a une autre langue, choisissez la piste via Langue du flux sur la carte du lecteur.

Sous-titres absents ou caractères cassés

Choisissez la bonne piste depuis la carte du lecteur ou Réglages › Lecteur › Sous-titres ; si les caractères sont cassés, changez l'encodage (UTF-8…). Taille/couleur/position se règlent dans le même panneau.

Affiches et infos de films manquantes

Vérifiez dans Réglages › Infos médias que vos clés TMDB/OMDb sont saisies et les services activés (clés gratuites). Récupérez en masse avec « Enrichir tout le contenu » ; corrigez une mauvaise association via Rechercher & associer le contenu du menu du contenu.

Premium acheté mais non débloqué / invisible sur un autre appareil

Vérifiez que vous êtes connecté avec le même compte Google — la licence se synchronise. Si la limite d'appareils est atteinte, retirez un ancien appareil sous Réglages › Comptes, Sync & Appareils. Au besoin, utilisez le code d'activation.

Après une longue veille de la TV, aucune chaîne ne s'ouvre

Fermez et rouvrez complètement l'app. L'app ferme automatiquement les lecteurs lors de la mise en veille ; si elle reste bloquée, un redémarrage règle le problème.

Comment transférer mes réglages sur un autre appareil ?

Créez un fichier avec Réglages › Autre › Sauvegarder les données, puis importez-le sur le nouvel appareil via Restaurer les données — ou connectez-vous avec Google et utilisez la sync.

Impossible de récupérer une chaîne / elle a disparu de la liste

La chaîne est peut-être masquée : Afficher les chaînes masquées dans le menu contextuel EPG ou Réglages › Contrôle parental › Chaînes masquées pour la rendre visible. Si elle est bloquée, elle s'ouvre avec le PIN. Si le groupe est masqué, vérifiez Réglages › Listes de lecture › Groupes de chaînes.

Comment supprimer mon compte ?

Réglages › Comptes, Sync & Appareils › Supprimer le compte supprime définitivement le compte avec vos données cloud. Détails : page Suppression du compte.
