Політика конфіденційності

Останнє оновлення: 6 вересня 2026 р.

Ця політика конфіденційності пояснює, як мобільний застосунок і застосунок для Android TV Tivi Ease Go («Застосунок») збирає, використовує, зберігає та захищає дані користувачів. Встановлюючи та використовуючи Застосунок, ви погоджуєтеся з цією політикою.

1. Дані, які ми збираємо

1.1. Інформація про обліковий запис (Firebase Authentication)

Застосунок використовує Firebase Authentication для створення облікового запису та входу. Збирається така інформація:

  • Адреса електронної пошти — для створення облікового запису та входу
  • Пароль — хешується Firebase, ніколи не зберігається у відкритому вигляді
  • Ім'я для відображення — необов'язкове ім'я профілю

1.2. Ідентифікатор пристрою

Для перевірки преміум-ліцензії та керування пристроями:

  • ANDROID_ID — ідентифікатор пристрою, що надається системою Android (Settings.Secure.ANDROID_ID)
  • Цей ідентифікатор використовується для відстеження пристроїв з активними преміум-ліцензіями
  • Цей ідентифікатор не використовується в рекламних цілях або для відстеження

1.3. Інформація про покупки (Google Play Billing)

Для перевірки ваших преміум-покупок:

  • Токен покупки — токен підтвердження покупки, наданий Google Play
  • Дата покупки та ідентифікатор продукту
  • Інформація отримується через Google Play Billing API та перевіряється за допомогою Firebase Cloud Functions

1.4. Інформація про IPTV / списки відтворення

Для відтворення ваших IPTV-списків відтворення:

  • URL-адреси серверів M3U/Xtream Codes та дані для входу — вводяться користувачем
  • Списки каналів і дані EPG (електронного програмного гіда) — завантажуються з IPTV-сервера користувача
  • Ця інформація використовується виключно для доступу до власного IPTV-сервісу користувача

1.5. Дані перегляду (лише на пристрої)

Наведені нижче дані зберігаються лише на вашому пристрої та не надсилаються на сервери:

  • Прогрес перегляду — позиція перегляду фільмів/серіалів
  • Вибране / Мій список — позначений контент
  • Записи — налаштування запису
  • Порядок каналів і приховані канали
  • Налаштування програвача

1.6. Дані синхронізації (Firebase Firestore)

Якщо ввімкнено синхронізацію облікового запису, до Firebase Firestore завантажуються такі дані:

  • Вибране, прогрес перегляду, налаштування запису
  • Конфігурація списку відтворення
  • Налаштування профілю

Ці дані прив'язані виключно до вашого облікового запису та не передаються іншим користувачам.

1.7. Запити метаданих (TMDB / OMDb)

Для збагачення метаданих фільмів і серіалів (постери, описи, акторський склад):

  • Назви фільмів/серіалів запитуються через API TMDB (themoviedb.org) та OMDb
  • Постери та фонові зображення завантажуються з CDN TMDB і кешуються на пристрої
  • Ці запити використовуються лише для збагачення контенту

2. Дані, які ми не збираємо

Застосунок не збирає і не обробляє такі дані:

  • Рекламні ідентифікатори (GAID / AAID / IDFA)
  • Персональні ідентифікаційні номери (національний ID, паспорт, адреса)
  • Дані про місцезнаходження (GPS)
  • Контакти / адресна книга
  • SMS або історія дзвінків
  • Історія браузера
  • Фотогалерея або доступ до камери
  • Доступ до мікрофона (крім голосового пошуку, лише за ініціативою користувача)

4. Зберігання та захист даних

4.1. Локальне сховище (на пристрої)

  • Прогрес перегляду, вибране та налаштування зберігаються на пристрої з використанням SharedPreferences
  • Постери та логотипи каналів кешуються у тимчасовому каталозі (макс. 150 МБ)
  • Записи зберігаються у пам'яті пристрою

4.2. Хмарне сховище (Firebase)

  • Дані автентифікації керуються Firebase Authentication
  • Дані синхронізації зберігаються у Firebase Firestore
  • Інформація про преміум-ліцензію зберігається у Firebase Firestore
  • Усі хмарні з'єднання шифруються через HTTPS/TLS

4.3. Заходи безпеки

  • Паролі ніколи не зберігаються у відкритому вигляді — хешування виконує Firebase Authentication
  • Виявлення root-доступу та перевірка підпису APK для контролю безпеки
  • Усі мережеві з'єднання шифруються через SSL/TLS
  • Дані доступу до IPTV-сервера зберігаються локально на пристрої та не передаються третім особам

  • Мета: Автентифікація, хмарна синхронізація, Cloud Functions
  • Дані: Електронна пошта, хеш пароля, дані синхронізації, ідентифікатор пристрою
  • Політика: Політика конфіденційності Firebase

5.2. Google Play Billing

  • Мета: Обробка преміум-покупок
  • Дані: Токен покупки, ідентифікатор продукту
  • Політика: Політика конфіденційності Google

5.3. TMDB (The Movie Database)

  • Мета: Надання метаданих і постерів фільмів/серіалів
  • Дані: Запити назв фільмів/серіалів (включно з IP-адресою)
  • Політика: Політика конфіденційності TMDB

5.4. OMDb API

  • Мета: Надання метаданих фільмів/серіалів
  • Дані: Запити назв фільмів/серіалів
  • Політика: Політика конфіденційності OMDb

6. Конфіденційність дітей

Застосунок не призначений для дітей віком до 13 років. Ми свідомо не збираємо персональні дані дітей віком до 13 років. Якщо вам стане відомо, що дитина віком до 13 років надала нам персональні дані, зв'яжіться з нами, і ми негайно видалимо такі дані.

7. Видалення даних

У Застосунку доступні такі варіанти видалення:

  • Видалення облікового запису: Налаштування → Обліковий запис → Видалити обліковий запис — усі ваші хмарні дані видаляються назавжди
  • Вихід з облікового запису: Ви можете вийти з облікового запису; локальні дані залишаться на пристрої
  • Очищення кешу: Налаштування → Сховище — можна очистити кеш постерів/логотипів
  • Експорт даних: Ви можете переглядати дані синхронізації у своєму обліковому записі

Усі запити на видалення обробляються протягом 30 днів.
