プライバシーポリシー

最終更新日：2026年9月6日

本プライバシーポリシーは、Tivi Ease Go（以下「本アプリ」）のモバイルおよび Android TV アプリケーションが、ユーザーデータをどのように収集、使用、保存、保護するかを説明するものです。本アプリをインストールして使用することにより、お客様は本ポリシーに同意したものとみなされます。

1. 収集するデータ

1.1. アカウント情報（Firebase Authentication）

本アプリは、アカウント作成とサインインに Firebase Authentication を使用します。以下の情報が収集されます：

  • メールアドレス — アカウント作成およびサインインのため
  • パスワード — Firebase によってハッシュ化され、平文で保存されることはありません
  • 表示名 — 任意のプロフィール名

1.2. デバイス識別子

プレミアムライセンスの確認およびデバイス管理のため：

  • ANDROID_ID — Android システムが提供するデバイス識別子（Settings.Secure.ANDROID_ID）
  • この識別子は、有効なプレミアムライセンスを持つデバイスを追跡するために使用されます
  • この識別子は広告やトラッキングの目的では使用されません

1.3. 購入情報（Google Play Billing）

プレミアム購入を確認するため：

  • 購入トークン — Google Play が提供する購入確認トークン
  • 購入日および商品 ID
  • 情報は Google Play Billing API を通じて取得され、Firebase Cloud Functions で検証されます

1.4. IPTV / プレイリスト情報

IPTV プレイリストを再生するため：

  • M3U/Xtream Codes サーバーの URL およびログイン認証情報 — ユーザーが入力
  • チャンネルリストおよび EPG（電子番組ガイド）データ — ユーザーの IPTV サーバーから取得
  • これらの情報はユーザー自身の IPTV サービスへのアクセスのみに使用されます

1.5. 視聴データ（デバイス上のみ）

以下のデータはお客様のデバイス上にのみ保存され、サーバーには送信されません：

  • 視聴進捗 — 映画/シリーズの視聴位置
  • お気に入り / マイリスト — マークされたコンテンツ
  • 録画 — 録画設定
  • チャンネルの並び順および非表示チャンネル
  • プレーヤー設定

1.6. 同期データ（Firebase Firestore）

アカウント同期が有効な場合、以下のデータが Firebase Firestore にアップロードされます：

  • お気に入り、視聴進捗、録画設定
  • プレイリスト設定
  • プロフィール設定

これらのデータはお客様のアカウントにのみ紐付けられ、他のユーザーと共有されることはありません。

1.7. メタデータクエリ（TMDB / OMDb）

映画およびシリーズのメタデータ（ポスター、説明、キャスト）を充実させるため：

  • 映画/シリーズのタイトルが TMDB（themoviedb.org）および OMDb API に対してクエリされます
  • ポスターおよび背景画像は TMDB CDN からダウンロードされ、デバイス上にキャッシュされます
  • これらのクエリはコンテンツ強化の目的のみに使用されます

2. 収集しないデータ

本アプリは以下のデータを収集または処理しません：

  • 広告識別子（GAID / AAID / IDFA）
  • 個人識別番号（国民 ID、パスポート、住所）
  • 位置情報データ（GPS）
  • 連絡先 / アドレス帳
  • SMS または通話履歴
  • ブラウザ履歴
  • フォトギャラリーまたはカメラへのアクセス
  • マイクへのアクセス（音声検索を除き、ユーザーが開始した場合のみ）

3. データ使用の目的

データ目的
メールアドレスとパスワードアカウント認証
デバイス識別子ライセンス確認およびデバイス管理

4. データの保存とセキュリティ

4.1. ローカルストレージ（デバイス上）

  • 視聴進捗、お気に入り、設定は SharedPreferences を使用してデバイス上に保存されます
  • ポスターおよびチャンネルロゴは一時ディレクトリにキャッシュされます（最大 150 MB）
  • 録画はデバイスのストレージに保存されます

4.2. クラウドストレージ（Firebase）

  • 認証データは Firebase Authentication によって管理されます
  • 同期データは Firebase Firestore に保存されます
  • プレミアムライセンス情報は Firebase Firestore に保存されます
  • すべてのクラウド通信は HTTPS/TLS で暗号化されます

4.3. セキュリティ対策

  • パスワードは平文で保存されることはありません — Firebase Authentication がハッシュ化を処理します
  • セキュリティチェックのためのルート検出および APK 署名検証
  • すべてのネットワーク通信は SSL/TLS で暗号化されます
  • IPTV サーバー認証情報はデバイス上にローカル保存され、第三者と共有されることはありません

5. 第三者サービス

5.1. Firebase (Google LLC)

  • 目的：認証、クラウド同期、Cloud Functions
  • データ：メールアドレス、パスワードハッシュ、同期データ、デバイス識別子
  • ポリシー：Firebase プライバシーポリシー

5.2. Google Play Billing

  • 目的：プレミアム購入処理
  • データ：購入トークン、商品 ID
  • ポリシー：Google プライバシーポリシー

5.3. TMDB (The Movie Database)

  • 目的：映画/シリーズのメタデータおよびポスターの提供
  • データ：映画/シリーズのタイトルクエリ（IP アドレスを含む）
  • ポリシー：TMDB プライバシーポリシー

5.4. OMDb API

  • 目的：映画/シリーズのメタデータ提供
  • データ：映画/シリーズのタイトルクエリ
  • ポリシー：OMDb プライバシーポリシー

6. 子供のプライバシー

本アプリは 13 歳未満の子供を対象としていません。当社は 13 歳未満の子供から個人データを故意に収集することはありません。13 歳未満の子供が当社に個人データを提供したことが判明した場合は、ご連絡ください。速やかに当該データを削除いたします。

7. データの削除

アプリ内では以下の削除オプションが利用できます：

  • アカウントの削除：設定 → アカウント → アカウントの削除 — すべてのクラウドデータが完全に削除されます
  • サインアウト：アカウントからサインアウトできます。ローカルデータはデバイスに残ります
  • キャッシュのクリア：設定 → ストレージ — ポスター/ロゴのキャッシュをクリアできます
  • データのエクスポート：アカウントから同期データを確認できます

すべての削除リクエストは 30 日以内に処理されます。

8. GDPR および KVKK への準拠

EU 一般データ保護規則（GDPR）およびトルコ個人データ保護法（KVKK）に基づき、お客様は以下の権利を有します：

  • データへのアクセス権
  • データの訂正権
  • データの消去権（「忘れられる権利」）
  • 処理の制限
  • データポータビリティ
  • 処理への異議申し立て

これらの権利を行使するには、tivieasego@gmail.com までご連絡ください。

9. Cookie および広告

本アプリは Cookie を使用しません。アプリ内に広告はありません。第三者の広告 SDK は含まれていません。

10. データ侵害通知

データ侵害が発生した場合、関連当局およびユーザーに 72 時間以内に通知されます。

11. ポリシーの変更

本プライバシーポリシーは随時更新される場合があります。重要な変更がある場合は、アプリ内通知またはメールでお知らせします。ポリシーの最終更新日はこのページの上部に記載されています。
