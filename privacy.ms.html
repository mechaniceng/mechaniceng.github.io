Dasar Privasi

Terakhir dikemas kini: 6 September 2026

Dasar privasi ini menerangkan cara aplikasi mudah alih dan Android TV Tivi Ease Go ("Aplikasi") mengumpul, menggunakan, menyimpan dan melindungi data pengguna. Dengan memasang dan menggunakan Aplikasi, anda bersetuju dengan dasar ini.

1. Data yang Kami Kumpulkan

1.1. Maklumat Akaun (Firebase Authentication)

Aplikasi menggunakan Firebase Authentication untuk penciptaan akaun dan log masuk. Maklumat berikut dikumpulkan:

  • Alamat e-mel — untuk penciptaan akaun dan log masuk
  • Kata laluan — di-hash oleh Firebase, tidak pernah disimpan dalam bentuk teks biasa
  • Nama paparan — nama profil pilihan

1.2. Pengecam Peranti

Untuk pengesahan lesen premium dan pengurusan peranti:

  • ANDROID_ID — pengecam peranti yang disediakan oleh sistem Android (Settings.Secure.ANDROID_ID)
  • Pengecam ini digunakan untuk mengesan peranti yang mempunyai lesen premium aktif
  • Pengecam ini tidak digunakan untuk tujuan pengiklanan atau penjejakan

1.3. Maklumat Pembelian (Google Play Billing)

Untuk mengesahkan pembelian premium anda:

  • Token pembelian — token pengesahan pembelian yang disediakan oleh Google Play
  • Tarikh pembelian dan ID produk
  • Maklumat diperoleh melalui Google Play Billing API dan disahkan melalui Firebase Cloud Functions

1.4. Maklumat IPTV / Senarai Main

Untuk memainkan senarai main IPTV anda:

  • URL pelayan M3U/Xtream Codes dan kelayakan log masuk — dimasukkan oleh pengguna
  • Senarai saluran dan data EPG (Electronic Program Guide) — diambil daripada pelayan IPTV pengguna
  • Maklumat ini digunakan semata-mata untuk mengakses perkhidmatan IPTV milik pengguna sendiri

1.5. Data Tontonan (Di Peranti Sahaja)

Data berikut disimpan hanya pada peranti anda dan tidak dihantar ke pelayan:

  • Kemajuan tontonan — kedudukan tontonan filem/siri
  • Kegemaran / Senarai Saya — kandungan yang ditandakan
  • Rakaman — tetapan rakaman
  • Susunan saluran dan saluran tersembunyi
  • Tetapan pemain

1.6. Data Penyegerakan (Firebase Firestore)

Apabila penyegerakan akaun didayakan, data berikut dimuat naik ke Firebase Firestore:

  • Kegemaran, kemajuan tontonan, tetapan rakaman
  • Konfigurasi senarai main
  • Tetapan profil

Data ini terikat secara eksklusif kepada akaun anda dan tidak dikongsi dengan pengguna lain.

1.7. Pertanyaan Metadata (TMDB / OMDb)

Untuk memperkayakan metadata filem dan siri (poster, penerangan, pelakon):

  • Tajuk filem/siri ditanyakan kepada API TMDB (themoviedb.org) dan OMDb
  • Imej poster dan latar belakang dimuat turun daripada TMDB CDN dan disimpan dalam cache pada peranti
  • Pertanyaan ini adalah untuk tujuan pengayaan kandungan sahaja

2. Data yang Kami Tidak Kumpulkan

Aplikasi tidak mengumpul atau memproses data berikut:

  • Pengecam pengiklanan (GAID / AAID / IDFA)
  • Nombor pengenalan peribadi (ID kebangsaan, pasport, alamat)
  • Data lokasi (GPS)
  • Kenalan / buku alamat
  • SMS atau sejarah panggilan
  • Sejarah pelayar
  • Galeri foto atau akses kamera
  • Akses mikrofon (kecuali untuk carian suara, hanya apabila dimulakan oleh pengguna)

4. Penyimpanan Data dan Keselamatan

4.1. Penyimpanan Setempat (Di Peranti)

  • Kemajuan tontonan, kegemaran dan tetapan disimpan pada peranti menggunakan SharedPreferences
  • Poster dan logo saluran disimpan dalam cache dalam direktori sementara (maks. 150 MB)
  • Rakaman disimpan dalam storan peranti

4.2. Penyimpanan Awan (Firebase)

  • Data pengesahan diuruskan oleh Firebase Authentication
  • Data penyegerakan disimpan dalam Firebase Firestore
  • Maklumat lesen premium disimpan dalam Firebase Firestore
  • Semua komunikasi awan disulitkan melalui HTTPS/TLS

4.3. Langkah Keselamatan

  • Kata laluan tidak pernah disimpan dalam bentuk teks biasa — Firebase Authentication mengendalikan hashing
  • Pengesanan root dan pengesahan tandatangan APK untuk pemeriksaan keselamatan
  • Semua komunikasi rangkaian disulitkan melalui SSL/TLS
  • Kelayakan pelayan IPTV disimpan secara setempat pada peranti dan tidak dikongsi dengan pihak ketiga

5. Perkhidmatan Pihak Ketiga

5.1. Firebase (Google LLC)

  • Tujuan: Pengesahan, penyegerakan awan, Cloud Functions
  • Data: E-mel, hash kata laluan, data penyegerakan, pengecam peranti
  • Dasar: Dasar Privasi Firebase

5.2. Google Play Billing

  • Tujuan: Pemprosesan pembelian premium
  • Data: Token pembelian, ID produk
  • Dasar: Dasar Privasi Google

5.3. TMDB (The Movie Database)

  • Tujuan: Penyediaan metadata dan poster filem/siri
  • Data: Pertanyaan tajuk filem/siri (termasuk alamat IP)
  • Dasar: Dasar Privasi TMDB

5.4. OMDb API

  • Tujuan: Penyediaan metadata filem/siri
  • Data: Pertanyaan tajuk filem/siri
  • Dasar: Dasar Privasi OMDb

6. Privasi Kanak-Kanak

Aplikasi tidak ditujukan kepada kanak-kanak di bawah 13 tahun. Kami tidak secara sengaja mengumpul data peribadi daripada kanak-kanak di bawah 13 tahun. Jika anda mengetahui bahawa kanak-kanak di bawah 13 tahun telah memberikan data peribadi kepada kami, sila hubungi kami dan kami akan memadamkan data tersebut dengan segera.

7. Pemadaman Data

Pilihan pemadaman berikut tersedia dalam Aplikasi:

  • Padam Akaun: Tetapan → Akaun → Padam Akaun — semua data awan anda dipadamkan secara kekal
  • Log Keluar: Anda boleh log keluar daripada akaun anda; data setempat kekal pada peranti
  • Kosongkan Cache: Tetapan → Storan — cache poster/logo boleh dikosongkan
  • Eksport Data: Anda boleh melihat data penyegerakan anda daripada akaun anda

Semua permintaan pemadaman diproses dalam tempoh 30 hari.
