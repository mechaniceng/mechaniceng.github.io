Tivi Ease Go — Instructions de suppression de compte

Vous pouvez supprimer votre compte Tivi Ease Go et toutes les données associées à tout moment. Vous trouverez ci-dessous les méthodes disponibles.

Méthode 1 : Suppression dans l'application (recommandée)

  1. Ouvrez l'application Tivi Ease Go sur votre appareil.
  2. Accédez à Paramètres → Compte.
  3. Sélectionnez Supprimer le compte.
  4. Confirmez la suppression en saisissant votre mot de passe lorsque vous y êtes invité.
  5. Votre compte et toutes les données cloud associées seront définitivement supprimés.

Méthode 2 : Demande par e-mail

Si vous ne pouvez pas accéder à l'application, vous pouvez demander la suppression de votre compte par e-mail :

  1. Envoyez un e-mail à tivieasego@gmail.com
  2. Utilisez l'objet : « Demande de suppression de compte »
  3. Indiquez l'adresse e-mail associée à votre compte Tivi Ease Go
  4. Nous traiterons votre demande dans un délai de 30 jours

Quelles données sont conservées

Les données suivantes peuvent être conservées sur votre appareil après la suppression du compte (vous pouvez les effacer manuellement) :

  • Cache local — affiches, logos de chaînes (à vider via Paramètres → Stockage → Vider le cache)
  • Enregistrements locaux — stockés dans l'espace de stockage de l'appareil (à supprimer manuellement)
  • Identifiants du serveur IPTV — stockés localement sur l'appareil (à effacer via les paramètres de l'application)

Remarque : Les enregistrements d'achat Google Play Billing sont conservés par Google et ne peuvent pas être supprimés par nos soins. Toutefois, l'association entre votre achat et votre compte supprimé est supprimée.

Délais de suppression

  • Suppression dans l'application : Immédiate — le compte est supprimé dès votre confirmation
  • Demande par e-mail : Sous 30 jours à compter de la réception de votre demande
