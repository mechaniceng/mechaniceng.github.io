İzləmək üçün lazım olan hər şey

Pleylistlərinizi əlavə edin, pultu götürün — qalanı TiviEase Go-dadır.

M3U və Xtream Codes

URL, yerli fayl və ya Xtream hesabı (server + istifadəçi adı + şifrə) ilə pleylist əlavə edin. Canlı, filmlər və seriallar avtomatik ayrılır.

Avtomatik dil və subtitr aşkarlanması

Çoxsəsli və subtirli məzmunda seçdiyiniz dili avtomatik tapır — düzgün səs yolu və subtitrlər hər başlıqda özü seçilir.

EPG bələdçisi

XMLTV mənbələrindən hər kanal üçün proqram axını. Avtomatik/əllə uyğunlaşdırma, vaxt sürüşməsi və keçmiş günlər dəstəyi.

Yazı və xatırlatmalar

EPG-də proqrama uzun basın: yazını planlaşdırın və ya xatırlatma yaradın. Bildiriş alın və ya kanalın özü açılsın.

Çoxekran (PIP)

Eyni anda 4 kanala qədər yan-yana izləyin. Bərabər görünüş, böyük ekran rejimi və hər kanalın ayrı idarəsi.

Profillər və valideyn nəzarəti

Hər kəsin öz profili var: ayrı sevimlilər, tarixçə və parametrlər. PIN kilidi, yaş həddi və kanal gizlətmə uşaqları qoruyur.

Yükləmə və oflayn

Filmləri və seriyaları yükləyin, internetsiz izləyin. SMB şəbəkə qovluqlarına yazı və yükləmə.

Telefon pult kimi

Telefonunuzu TV pultuna çevirin: D-pad, rəqəm düymələri, rəngli düymələr, klaviatura — hamısı tətbiqdə.

DLNA və yayım

Şəbəkənizdəki DLNA cihazlarına yayınlayın və ya telefondan TV-yə məzmun göndərin.

TMDB və OMDb dəstəyi

Öz pulsuz API açarlarınızla posterlər, təsvirlər, aktyorlar və IMDb reytinqləri. Ağıllı keş ilə sürətli yüklənmə.

Tətbiqi açın

İlk açılışda qarşılama ekranı gəlir: «Pleylist əlavə et» kartını seçin.

Pleylist əlavə edin

M3U üçün URL və ya fayl daxil edin; Xtream üçün: server + istifadəçi adı + şifrə.

EPG əlavə edin

XMLTV ünvanınızı Parametrlər › TV bələdçisi › «EPG mənbəsi əlavə et» bölməsinə daxil edin; kanallar avtomatik uyğunlaşır.

İzləməyə başlayın

Yuxarı menyuda TV seçin, kanala basın — oynatma tam ekran başlayır.
