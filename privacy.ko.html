개인정보 처리방침

최종 업데이트: 2026년 9월 6일

본 개인정보 처리방침은 Tivi Ease Go(이하 "애플리케이션") 모바일 및 Android TV 앱이 사용자 데이터를 수집, 사용, 저장 및 보호하는 방법을 설명합니다. 애플리케이션을 설치하고 사용함으로써 귀하는 본 정책에 동의하는 것으로 간주됩니다.

1. 수집하는 데이터

1.1. 계정 정보(Firebase Authentication)

애플리케이션은 계정 생성 및 로그인을 위해 Firebase Authentication을 사용합니다. 다음 정보가 수집됩니다:

  • 이메일 주소 — 계정 생성 및 로그인용
  • 비밀번호 — Firebase에 의해 해시 처리되며 평문으로 저장되지 않습니다
  • 표시 이름 — 선택적 프로필 이름

1.2. 기기 식별자

프리미엄 라이선스 확인 및 기기 관리를 위해:

  • ANDROID_ID — Android 시스템에서 제공하는 기기 식별자(Settings.Secure.ANDROID_ID)
  • 이 식별자는 활성 프리미엄 라이선스가 있는 기기를 추적하는 데 사용됩니다
  • 이 식별자는 광고 또는 추적 목적으로 사용되지 않습니다

1.3. 구매 정보(Google Play Billing)

프리미엄 구매를 확인하기 위해:

  • 구매 토큰 — Google Play에서 제공하는 구매 확인 토큰
  • 구매 날짜 및 상품 ID
  • 정보는 Google Play Billing API를 통해 얻고 Firebase Cloud Functions로 검증됩니다

1.4. IPTV / 재생목록 정보

IPTV 재생목록을 재생하기 위해:

  • M3U/Xtream Codes 서버 URL 및 로그인 자격 증명 — 사용자가 입력
  • 채널 목록 및 EPG(전자 프로그램 가이드) 데이터 — 사용자의 IPTV 서버에서 가져옴
  • 이 정보는 사용자 자신의 IPTV 서비스에 접근하기 위해서만 사용됩니다

1.5. 시청 데이터(기기 내 전용)

다음 데이터는 기기에만 저장되며 서버로 전송되지 않습니다:

  • 시청 진행 — 영화/시리즈 시청 위치
  • 즐겨찾기 / 내 목록 — 표시된 콘텐츠
  • 녹화 — 녹화 설정
  • 채널 순서 및 숨겨진 채널
  • 플레이어 설정

1.6. 동기화 데이터(Firebase Firestore)

계정 동기화가 활성화되면 다음 데이터가 Firebase Firestore에 업로드됩니다:

  • 즐겨찾기, 시청 진행, 녹화 설정
  • 재생목록 구성
  • 프로필 설정

이 데이터는 귀하의 계정에만 연결되며 다른 사용자와 공유되지 않습니다.

1.7. 메타데이터 쿼리(TMDB / OMDb)

영화 및 시리즈 메타데이터(포스터, 설명, 출연진)를 보강하기 위해:

  • 영화/시리즈 제목이 TMDB(themoviedb.org) 및 OMDb API에 대해 쿼리됩니다
  • 포스터 및 배경 이미지는 TMDB CDN에서 다운로드되어 기기에 캐시됩니다
  • 이 쿼리는 콘텐츠 보강 목적으로만 사용됩니다

2. 수집하지 않는 데이터

애플리케이션은 다음 데이터를 수집하거나 처리하지 않습니다:

  • 광고 식별자(GAID / AAID / IDFA)
  • 개인 식별 번호(주민등록번호, 여권, 주소)
  • 위치 데이터(GPS)
  • 연락처 / 주소록
  • SMS 또는 통화 기록
  • 브라우저 기록
  • 사진 갤러리 또는 카메라 접근
  • 마이크 접근(음성 검색 제외, 사용자가 시작한 경우에만)

3. 데이터 사용 목적

데이터목적

4. 데이터 저장 및 보안

4.1. 로컬 저장(기기 내)

  • 시청 진행, 즐겨찾기 및 설정은 SharedPreferences를 사용하여 기기에 저장됩니다
  • 포스터 및 채널 로고는 임시 디렉터리에 캐시됩니다(최대 150MB)
  • 녹화는 기기 저장소에 저장됩니다

4.2. 클라우드 저장(Firebase)

  • 인증 데이터는 Firebase Authentication으로 관리됩니다
  • 동기화 데이터는 Firebase Firestore에 저장됩니다
  • 프리미엄 라이선스 정보는 Firebase Firestore에 저장됩니다
  • 모든 클라우드 통신은 HTTPS/TLS로 암호화됩니다

4.3. 보안 조치

  • 비밀번호는 평문으로 저장되지 않습니다 — Firebase Authentication이 해시 처리를 담당합니다
  • 보안 점검을 위한 루팅 감지 및 APK 서명 검증
  • 모든 네트워크 통신은 SSL/TLS로 암호화됩니다
  • IPTV 서버 자격 증명은 기기에 로컬로 저장되며 제3자와 공유되지 않습니다

5. 제3자 서비스

5.1. Firebase (Google LLC)

  • 목적: 인증, 클라우드 동기화, Cloud Functions
  • 데이터: 이메일, 비밀번호 해시, 동기화 데이터, 기기 식별자
  • 정책: Firebase 개인정보 처리방침

5.2. Google Play Billing

  • 목적: 프리미엄 구매 처리
  • 데이터: 구매 토큰, 상품 ID
  • 정책: Google 개인정보 처리방침

5.3. TMDB (The Movie Database)

  • 목적: 영화/시리즈 메타데이터 및 포스터 제공
  • 데이터: 영화/시리즈 제목 쿼리(IP 주소 포함)
  • 정책: TMDB 개인정보 처리방침

5.4. OMDb API

  • 목적: 영화/시리즈 메타데이터 제공
  • 데이터: 영화/시리즈 제목 쿼리
  • 정책: OMDb 개인정보 처리방침

6. 아동의 개인정보

애플리케이션은 13세 미만의 아동을 대상으로 하지 않습니다. 당사는 13세 미만 아동의 개인 데이터를 고의로 수집하지 않습니다. 13세 미만 아동이 당사에 개인 데이터를 제공한 사실을 알게 되면 저희에게 연락해 주시기 바랍니다. 즉시 해당 데이터를 삭제하겠습니다.

7. 데이터 삭제

앱 내에서 다음 삭제 옵션을 사용할 수 있습니다:

  • 계정 삭제: 설정 → 계정 → 계정 삭제 — 모든 클라우드 데이터가 영구적으로 삭제됩니다
  • 로그아웃: 계정에서 로그아웃할 수 있습니다. 로컬 데이터는 기기에 남습니다
  • 캐시 지우기: 설정 → 저장소 — 포스터/로고 캐시를 지울 수 있습니다
  • 데이터보내기: 계정에서 동기화 데이터를 볼 수 있습니다

모든 삭제 요청은 30일 이내에 처리됩니다.

8. GDPR 및 KVKK 준수

EU 일반 데이터 보호 규정(GDPR) 및 튀르키예 개인 데이터 보호법(KVKK)에 따라 귀하는 다음 권리를 갖습니다:

  • 데이터 접근권
  • 데이터 정정권
  • 데이터 삭제권("잊힐 권리")
  • 처리 제한
  • 데이터 이동성
  • 처리에 대한 이의 제기

이러한 권리를 행사하려면 tivieasego@gmail.com으로 문의하십시오.

9. 쿠키 및 광고

애플리케이션은 쿠키를 사용하지 않습니다. 앱 내에 광고가 없습니다. 제3자 광고 SDK를 포함하지 않습니다.

10. 데이터 침해 통지

데이터 침해가 발생할 경우 관련 기관 및 사용자에게 72시간 이내에 통지됩니다.
