Begäran om radering av konto

Tivi Ease Go — Instruktioner för radering av konto

Du kan när som helst radera ditt Tivi Ease Go-konto och all tillhörande data. Nedan finns de tillgängliga metoderna.

Metod 1: Radering i appen (rekommenderas)

  1. Öppna appen Tivi Ease Go på din enhet.
  2. Gå till Inställningar → Konto.
  3. Välj Radera konto.
  4. Bekräfta raderingen genom att ange ditt lösenord när du uppmanas.
  5. Ditt konto och all tillhörande molndata raderas permanent.

Metod 2: Begäran via e-post

Om du inte kan komma åt appen kan du begära radering av kontot via e-post:

  1. Skicka ett e-postmeddelande till tivieasego@gmail.com
  2. Använd ämnesraden: "Begäran om radering av konto"
  3. Ange e-postadressen som är kopplad till ditt Tivi Ease Go-konto
  4. Vi behandlar din begäran inom 30 dagar

Vilken data raderas

När du raderar ditt konto tas följande data bort permanent:

Vilken data behålls

Följande data kan finnas kvar på din enhet efter att kontot raderats (du kan rensa den manuellt):

  • Lokal cache — affischer, kanallogotyper (rensa via Inställningar → Lagring → Rensa cache)
  • Lokala inspelningar — lagras i enhetens lagring (radera manuellt)
  • IPTV-serveruppgifter — lagras lokalt på enheten (rensa via appinställningarna)

Obs: Köphandlingar i Google Play Billing behålls av Google och kan inte raderas av oss. Kopplingen mellan ditt köp och ditt raderade konto tas dock bort.

Tidslinje för radering

  • Radering i appen: Omedelbar — kontot raderas så snart du bekräftar
  • Begäran via e-post: Inom 30 dagar från mottagandet av din begäran
