นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 6 กันยายน 2026

นโยบายความเป็นส่วนตัวฉบับนี้อธิบายว่าแอปพลิเคชันมือถือและ Android TV ของ Tivi Ease Go ("แอปพลิเคชัน") เก็บรวบรวม ใช้ จัดเก็บ และปกป้องข้อมูลผู้ใช้อย่างไร การติดตั้งและใช้งานแอปพลิเคชันถือว่าคุณยอมรับนโยบายนี้

1. ข้อมูลที่เราเก็บรวบรวม

1.1. ข้อมูลบัญชี (Firebase Authentication)

แอปพลิเคชันใช้ Firebase Authentication สำหรับการสร้างบัญชีและลงชื่อเข้าใช้ ข้อมูลต่อไปนี้จะถูกเก็บรวบรวม:

  • ที่อยู่อีเมล — สำหรับการสร้างบัญชีและลงชื่อเข้าใช้
  • รหัสผ่าน — ถูกแฮชโดย Firebase และไม่ถูกจัดเก็บเป็นข้อความธรรมดา
  • ชื่อที่แสดง — ชื่อโปรไฟล์ (ไม่บังคับ)

1.2. ตัวระบุอุปกรณ์

สำหรับการยืนยันใบอนุญาตพรีเมียมและการจัดการอุปกรณ์:

  • ANDROID_ID — ตัวระบุอุปกรณ์ที่ระบบ Android จัดเตรียมไว้ (Settings.Secure.ANDROID_ID)
  • ตัวระบุนี้ใช้เพื่อติดตามว่าอุปกรณ์ใดมีใบอนุญาตพรีเมียมที่ใช้งานอยู่
  • ตัวระบุนี้ไม่ได้ใช้เพื่อวัตถุประสงค์ทางการโฆษณาหรือการติดตาม

1.3. ข้อมูลการซื้อ (Google Play Billing)

เพื่อยืนยันการซื้อพรีเมียมของคุณ:

  • โทเคนการซื้อ — โทเคนยืนยันการซื้อที่ Google Play จัดเตรียมไว้
  • วันที่ซื้อและรหัสผลิตภัณฑ์
  • ข้อมูลได้รับผ่าน Google Play Billing API และยืนยันผ่าน Firebase Cloud Functions

1.4. ข้อมูล IPTV / เพลย์ลิสต์

เพื่อเล่นเพลย์ลิสต์ IPTV ของคุณ:

  • URL เซิร์ฟเวอร์ M3U/Xtream Codes และข้อมูลเข้าสู่ระบบ — ผู้ใช้ป้อนเอง
  • รายการช่องและข้อมูล EPG (Electronic Program Guide) — ดึงมาจากเซิร์ฟเวอร์ IPTV ของผู้ใช้
  • ข้อมูลนี้ใช้เพื่อเข้าถึงบริการ IPTV ของผู้ใช้เองเท่านั้น

1.5. ข้อมูลการรับชม (บนอุปกรณ์เท่านั้น)

ข้อมูลต่อไปนี้จัดเก็บบนอุปกรณ์ของคุณเท่านั้นและไม่ถูกส่งไปยังเซิร์ฟเวอร์:

  • ความคืบหน้าการรับชม — ตำแหน่งการรับชมภาพยนตร์/ซีรีส์
  • รายการโปรด / รายการของฉัน — เนื้อหาที่ทำเครื่องหมายไว้
  • การบันทึก — การตั้งค่าการบันทึก
  • การจัดเรียงช่องและช่องที่ซ่อนไว้
  • การตั้งค่าเพลเยอร์

1.6. ข้อมูลการซิงค์ (Firebase Firestore)

เมื่อเปิดใช้การซิงค์บัญชี ข้อมูลต่อไปนี้จะถูกอัปโหลดไปยัง Firebase Firestore:

  • รายการโปรด ความคืบหน้าการรับชม การตั้งค่าการบันทึก
  • การกำหนดค่าเพลย์ลิสต์
  • การตั้งค่าโปรไฟล์

ข้อมูลนี้ผูกติดกับบัญชีของคุณโดยเฉพาะและไม่ถูกแบ่งปันกับผู้ใช้รายอื่น

1.7. การสืบค้นข้อมูลเมทาดาทา (TMDB / OMDb)

เพื่อเสริมข้อมูลเมทาดาทาของภาพยนตร์และซีรีส์ (โปสเตอร์ คำอธิบาย นักแสดง):

  • ชื่อภาพยนตร์/ซีรีส์จะถูกสืบค้นจาก TMDB (themoviedb.org) และ OMDb API
  • รูปภาพโปสเตอร์และแบ็กดรอปจะถูกดาวน์โหลดจาก TMDB CDN และแคชไว้บนอุปกรณ์
  • การสืบค้นเหล่านี้มีไว้เพื่อวัตถุประสงค์ในการเสริมเนื้อหาเท่านั้น

2. ข้อมูลที่เราไม่เก็บรวบรวม

แอปพลิเคชันไม่เก็บรวบรวมหรือประมวลผลข้อมูลต่อไปนี้:

  • ตัวระบุโฆษณา (GAID / AAID / IDFA)
  • หมายเลขประจำตัวส่วนบุคคล (บัตรประชาชน หนังสือเดินทาง ที่อยู่)
  • ข้อมูลตำแหน่ง (GPS)
  • รายชื่อผู้ติดต่อ / สมุดที่อยู่
  • SMS หรือประวัติการโทร
  • ประวัติเบราว์เซอร์
  • แกลเลอรีรูปภาพหรือการเข้าถึงกล้อง
  • การเข้าถึงไมโครโฟน (ยกเว้นการค้นหาด้วยเสียง เฉพาะเมื่อผู้ใช้เริ่มใช้งานเท่านั้น)

3. วัตถุประสงค์การใช้ข้อมูล

ข้อมูลวัตถุประสงค์
อีเมลและรหัสผ่านการยืนยันตัวตนบัญชี
ตัวระบุอุปกรณ์การยืนยันใบอนุญาตและการจัดการอุปกรณ์
โทเคนการซื้อการยืนยันการซื้อพรีเมียม
ข้อมูลเข้าสู่ระบบเซิร์ฟเวอร์ IPTVการเข้าถึงเนื้อหา IPTV ของผู้ใช้เอง
ข้อมูลการรับชมประสบการณ์ผู้ใช้ (บนอุปกรณ์หรือซิงค์)
ชื่อภาพยนตร์/ซีรีส์การเสริมเมทาดาทา TMDB/OMDb

4. การจัดเก็บข้อมูลและความปลอดภัย

4.1. การจัดเก็บในเครื่อง (บนอุปกรณ์)

  • ความคืบหน้าการรับชม รายการโปรด และการตั้งค่าจะถูกจัดเก็บบนอุปกรณ์โดยใช้ SharedPreferences
  • โปสเตอร์และโลโก้ช่องจะถูกแคชในไดเรกทอรีชั่วคราว (สูงสุด 150 MB)
  • การบันทึกจะถูกจัดเก็บในที่จัดเก็บข้อมูลของอุปกรณ์

4.2. การจัดเก็บบนคลาวด์ (Firebase)

  • ข้อมูลการยืนยันตัวตนจัดการโดย Firebase Authentication
  • ข้อมูลการซิงค์จัดเก็บใน Firebase Firestore
  • ข้อมูลใบอนุญาตพรีเมียมจัดเก็บใน Firebase Firestore
  • การสื่อสารบนคลาวด์ทั้งหมดเข้ารหัสผ่าน HTTPS/TLS

4.3. มาตรการรักษาความปลอดภัย

  • รหัสผ่านไม่ถูกจัดเก็บเป็นข้อความธรรมดา — Firebase Authentication จัดการการแฮช
  • การตรวจจับรูทและการยืนยันลายเซ็น APK สำหรับการตรวจสอบความปลอดภัย
  • การสื่อสารเครือข่ายทั้งหมดเข้ารหัสผ่าน SSL/TLS
  • ข้อมูลเข้าสู่ระบบเซิร์ฟเวอร์ IPTV จัดเก็บในเครื่องบนอุปกรณ์และไม่ถูกแบ่งปันกับบุคคลที่สาม

5. บริการของบุคคลที่สาม

5.1. Firebase (Google LLC)

  • วัตถุประสงค์: การยืนยันตัวตน การซิงค์บนคลาวด์ Cloud Functions
  • ข้อมูล: อีเมล แฮชรหัสผ่าน ข้อมูลการซิงค์ ตัวระบุอุปกรณ์
  • นโยบาย: นโยบายความเป็นส่วนตัวของ Firebase

5.2. Google Play Billing

  • วัตถุประสงค์: การประมวลผลการซื้อพรีเมียม
  • ข้อมูล: โทเคนการซื้อ รหัสผลิตภัณฑ์
  • นโยบาย: นโยบายความเป็นส่วนตัวของ Google

5.3. TMDB (The Movie Database)

  • วัตถุประสงค์: การจัดเตรียมเมทาดาทาและโปสเตอร์ภาพยนตร์/ซีรีส์
  • ข้อมูล: การสืบค้นชื่อภาพยนตร์/ซีรีส์ (รวมถึงที่อยู่ IP)
  • นโยบาย: นโยบายความเป็นส่วนตัวของ TMDB

5.4. OMDb API

  • วัตถุประสงค์: การจัดเตรียมเมทาดาทาภาพยนตร์/ซีรีส์
  • ข้อมูล: การสืบค้นชื่อภาพยนตร์/ซีรีส์
  • นโยบาย: นโยบายความเป็นส่วนตัวของ OMDb

6. ความเป็นส่วนตัวของเด็ก

แอปพลิเคชันไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี เราไม่ได้เก็บรวบรวมข้อมูลส่วนบุคคลจากเด็กอายุต่ำกว่า 13 ปีโดยเจตนา หากคุณทราบว่าเด็กอายุต่ำกว่า 13 ปีได้ให้ข้อมูลส่วนบุคคลแก่เรา โปรดติดต่อเราและเราจะลบข้อมูลดังกล่าวทันที

7. การลบข้อมูล

ตัวเลือกการลบต่อไปนี้มีให้ภายในแอปพลิเคชัน:

  • ลบบัญชี: การตั้งค่า → บัญชี → ลบบัญชี — ข้อมูลบนคลาวด์ทั้งหมดของคุณจะถูกลบอย่างถาวร
  • ลงชื่อออก: คุณสามารถลงชื่อออกจากบัญชีของคุณ ข้อมูลในเครื่องจะยังคงอยู่บนอุปกรณ์
  • ล้างแคช: การตั้งค่า → ที่จัดเก็บข้อมูล — สามารถล้างแคชโปสเตอร์/โลโก้ได้
  • ส่งออกข้อมูล: คุณสามารถดูข้อมูลการซิงค์ของคุณจากบัญชีของคุณ

คำขอลบทั้งหมดจะได้รับการดำเนินการภายใน 30 วัน

8. การปฏิบัติตาม GDPR และ KVKK

ภายใต้กฎระเบียบการคุ้มครองข้อมูลทั่วไปของสหภาพยุโรป (GDPR) และกฎหมายคุ้มครองข้อมูลส่วนบุคคลของตุรกี (KVKK) คุณมีสิทธิต่อไปนี้:

  • การเข้าถึงข้อมูลของคุณ
  • การแก้ไขข้อมูลของคุณ
  • การลบข้อมูลของคุณ ("สิทธิในการถูกลืม")
  • การจำกัดการประมวลผล
  • ความสามารถในการเคลื่อนย้ายข้อมูล
  • การคัดค้านการประมวลผล

หากต้องการใช้สิทธิเหล่านี้ โปรดติดต่อเราที่ tivieasego@gmail.com

9. คุกกี้และการโฆษณา

แอปพลิเคชันไม่ใช้คุกกี้ ไม่มีโฆษณาภายในแอปพลิเคชัน และไม่มี SDK โฆษณาของบุคคลที่สาม

10. การแจ้งเตือนการละเมิดข้อมูล

ในกรณีที่เกิดการละเมิดข้อมูล หน่วยงานที่เกี่ยวข้องและผู้ใช้จะได้รับแจ้งภายใน 72 ชั่วโมง

11. การเปลี่ยนแปลงนโยบาย

นโยบายความเป็นส่วนตัวนี้อาจได้รับการอัปเดตเป็นครั้งคราว ในกรณีที่มีการเปลี่ยนแปลงที่สำคัญ คุณจะได้รับแจ้งผ่านการแจ้งเตือนในแอปหรืออีเมล วันที่อัปเดตล่าสุดของนโยบายระบุไว้ที่ด้านบนของหน้านี้
