Kebijakan Privasi

Terakhir diperbarui: 6 September 2026

Kebijakan privasi ini menjelaskan bagaimana aplikasi seluler dan Android TV Tivi Ease Go ("Aplikasi") mengumpulkan, menggunakan, menyimpan, dan melindungi data pengguna. Dengan menginstal dan menggunakan Aplikasi, Anda menyetujui kebijakan ini.

1. Data yang Kami Kumpulkan

1.1. Informasi Akun (Firebase Authentication)

Aplikasi menggunakan Firebase Authentication untuk pembuatan akun dan proses masuk. Informasi berikut dikumpulkan:

  • Alamat email — untuk pembuatan akun dan proses masuk
  • Kata sandi — di-hash oleh Firebase, tidak pernah disimpan dalam bentuk teks biasa
  • Nama tampilan — nama profil opsional

1.2. Pengidentifikasi Perangkat

Untuk verifikasi lisensi premium dan pengelolaan perangkat:

  • ANDROID_ID — pengidentifikasi perangkat yang disediakan oleh sistem Android (Settings.Secure.ANDROID_ID)
  • Pengidentifikasi ini digunakan untuk melacak perangkat mana yang memiliki lisensi premium aktif
  • Pengidentifikasi ini tidak digunakan untuk tujuan periklanan atau pelacakan

1.3. Informasi Pembelian (Google Play Billing)

Untuk memverifikasi pembelian premium Anda:

  • Token pembelian — token verifikasi pembelian yang disediakan oleh Google Play
  • Tanggal pembelian dan ID produk
  • Informasi diperoleh melalui Google Play Billing API dan diverifikasi melalui Firebase Cloud Functions

1.4. Informasi IPTV / Playlist

Untuk memutar playlist IPTV Anda:

  • URL server M3U/Xtream Codes dan kredensial login — dimasukkan oleh pengguna
  • Daftar saluran dan data EPG (Electronic Program Guide) — diambil dari server IPTV pengguna
  • Informasi ini digunakan semata-mata untuk mengakses layanan IPTV milik pengguna sendiri

1.5. Data Tontonan (Hanya di Perangkat)

Data berikut hanya disimpan di perangkat Anda dan tidak dikirim ke server:

  • Kemajuan menonton — posisi tontonan film/serial
  • Favorit / Daftar Saya — konten yang ditandai
  • Rekaman — pengaturan perekaman
  • Urutan saluran dan saluran tersembunyi
  • Pengaturan pemutar

1.6. Data Sinkronisasi (Firebase Firestore)

Saat sinkronisasi akun diaktifkan, data berikut diunggah ke Firebase Firestore:

  • Favorit, kemajuan menonton, pengaturan perekaman
  • Konfigurasi playlist
  • Pengaturan profil

Data ini terikat secara eksklusif pada akun Anda dan tidak dibagikan dengan pengguna lain.

1.7. Kueri Metadata (TMDB / OMDb)

Untuk memperkaya metadata film dan serial (poster, deskripsi, pemeran):

  • Judul film/serial dikuerikan pada API TMDB (themoviedb.org) dan OMDb
  • Gambar poster dan latar diunduh dari TMDB CDN dan disimpan dalam cache di perangkat
  • Kueri ini hanya untuk tujuan pengayaan konten

2. Data yang Tidak Kami Kumpulkan

Aplikasi tidak mengumpulkan atau memproses data berikut:

  • Pengidentifikasi iklan (GAID / AAID / IDFA)
  • Nomor identitas pribadi (KTP, paspor, alamat)
  • Data lokasi (GPS)
  • Kontak / buku alamat
  • SMS atau riwayat panggilan
  • Riwayat peramban
  • Galeri foto atau akses kamera
  • Akses mikrofon (kecuali untuk pencarian suara, hanya saat dimulai oleh pengguna)

4. Penyimpanan Data dan Keamanan

4.1. Penyimpanan Lokal (Di Perangkat)

  • Kemajuan menonton, favorit, dan pengaturan disimpan di perangkat menggunakan SharedPreferences
  • Poster dan logo saluran disimpan dalam cache di direktori sementara (maks. 150 MB)
  • Rekaman disimpan di penyimpanan perangkat

4.2. Penyimpanan Cloud (Firebase)

  • Data autentikasi dikelola oleh Firebase Authentication
  • Data sinkronisasi disimpan di Firebase Firestore
  • Informasi lisensi premium disimpan di Firebase Firestore
  • Semua komunikasi cloud dienkripsi melalui HTTPS/TLS

4.3. Langkah-Langkah Keamanan

  • Kata sandi tidak pernah disimpan dalam bentuk teks biasa — Firebase Authentication menangani hashing
  • Deteksi root dan verifikasi tanda tangan APK untuk pemeriksaan keamanan
  • Semua komunikasi jaringan dienkripsi melalui SSL/TLS
  • Kredensial server IPTV disimpan secara lokal di perangkat dan tidak dibagikan dengan pihak ketiga

5. Layanan Pihak Ketiga

5.1. Firebase (Google LLC)

  • Tujuan: Autentikasi, sinkronisasi cloud, Cloud Functions
  • Data: Email, hash kata sandi, data sinkronisasi, pengidentifikasi perangkat
  • Kebijakan: Kebijakan Privasi Firebase

5.2. Google Play Billing

  • Tujuan: Pemrosesan pembelian premium
  • Data: Token pembelian, ID produk
  • Kebijakan: Kebijakan Privasi Google

5.3. TMDB (The Movie Database)

  • Tujuan: Penyediaan metadata dan poster film/serial
  • Data: Kueri judul film/serial (termasuk alamat IP)
  • Kebijakan: Kebijakan Privasi TMDB

5.4. OMDb API

  • Tujuan: Penyediaan metadata film/serial
  • Data: Kueri judul film/serial
  • Kebijakan: Kebijakan Privasi OMDb

6. Privasi Anak-Anak

Aplikasi tidak ditujukan untuk anak-anak di bawah 13 tahun. Kami tidak dengan sengaja mengumpulkan data pribadi dari anak-anak di bawah 13 tahun. Jika Anda mengetahui bahwa anak di bawah 13 tahun telah memberikan data pribadi kepada kami, silakan hubungi kami dan kami akan segera menghapus data tersebut.

7. Penghapusan Data

Opsi penghapusan berikut tersedia di dalam Aplikasi:

  • Hapus Akun: Pengaturan → Akun → Hapus Akun — semua data cloud Anda dihapus secara permanen
  • Keluar: Anda dapat keluar dari akun Anda; data lokal tetap tersimpan di perangkat
  • Hapus Cache: Pengaturan → Penyimpanan — cache poster/logo dapat dihapus
  • Ekspor Data: Anda dapat melihat data sinkronisasi Anda dari akun Anda

Semua permintaan penghapusan diproses dalam waktu 30 hari.

8. Kepatuhan terhadap GDPR dan KVKK

Berdasarkan Peraturan Perlindungan Data Umum Uni Eropa (GDPR) dan Undang-Undang Perlindungan Data Pribadi Turki (KVKK), Anda memiliki hak-hak berikut:

  • Akses ke data Anda
  • Pembetulan data Anda
  • Penghapusan data Anda ("hak untuk dilupakan")
  • Pembatasan pemrosesan
  • Portabilitas data
  • Keberatan terhadap pemrosesan

Untuk menggunakan hak-hak ini, hubungi kami di tivieasego@gmail.com.

9. Cookie dan Periklanan

Aplikasi tidak menggunakan cookie. Tidak ada iklan di dalam Aplikasi. Aplikasi tidak mengandung SDK periklanan pihak ketiga.

10. Pemberitahuan Pelanggaran Data

Jika terjadi pelanggaran data, otoritas terkait dan pengguna akan diberitahu dalam waktu 72 jam.

11. Perubahan Kebijakan

Kebijakan privasi ini dapat diperbarui dari waktu ke waktu. Jika terjadi perubahan signifikan, Anda akan diberitahu melalui notifikasi dalam aplikasi atau email. Tanggal pembaruan terakhir kebijakan ditunjukkan di bagian atas halaman ini.
