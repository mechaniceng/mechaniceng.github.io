入门

TiviEase Go 在一个应用中同时支持 Android TV 和手机/平板。应用本身不提供频道或内容——您需要添加来自自己 IPTV 服务商的 M3U 播放列表或 Xtream Codes 账户。

首次启动界面

如果尚未配置任何播放列表，打开应用时会显示欢迎屏幕。共有四张卡片：

卡片功能
添加播放列表
M3U / Xtream		带您进入主界面并打开添加表单。详见：添加播放列表。
Google 登录
云端同步		使用 Google 账户登录；加载云端保存的源、收藏和历史记录，然后自动更新播放列表。
二维码登录
用手机扫描 TV		在电视上显示有效期 3 分钟的二维码；用手机应用扫码并确认，电视即登录同一账户。
设置
系统与个人资料		如果您想在添加播放列表前先浏览，可打开设置界面。

提示：如果您已在其他设备上使用 TiviEase Go，最快的方式是 Google 登录或二维码登录——所有列表和设置会自动同步过来。

选择个人资料

如果设备上配置了多个个人资料，启动时会显示「选择个人资料」界面。用方向键 + OK 选择。带 PIN 的资料会先要求输入密码。每个资料拥有独立的收藏、「我的列表」内容、历史记录和个人设置。

  • 添加/编辑资料：设置 › 个人资料（见个人资料管理）。
  • 使用中切换资料：点击顶部栏的个人资料头像。

二维码登录 TV 移动端

无需在电视上输入凭据，用手机操作：

  1. 在电视上打开二维码登录卡片（欢迎屏幕或设置 › 账户）——出现二维码，有效期 3 分钟。
  2. 在手机上打开 TiviEase Go 应用，用扫码器扫描电视上的二维码。
  3. 在手机上点击「登录」——您会看到「已确认——电视正在登录」。
  4. 电视会在几秒内登录手机的账户；播放列表和设置随之同步。

如果二维码过期，关闭并重新打开窗口即可生成新码。二维码登录要求手机上的应用已打开并已登录。

Google 登录与同步

使用 Google 账户登录后，以下内容会在设备间同步：源/列表配置、收藏、「我的列表」、历史记录、个人资料和高级版许可。首次登录后，源和 EPG 会自动下载——无需手动更新。

  • 同步设置与已连接设备：设置 › 账户、同步与设备。
  • 也可以不使用账户——数据保留在设备本地。

添加播放列表

支持两种源类型：M3U（URL 或本地文件）和 Xtream Codes（服务器 + 凭据）。添加后内容自动分为直播 / 电影 / 剧集。

从哪里添加？

  • 欢迎屏幕上的添加播放列表卡片，
  • 或从设置 › 播放列表 › 添加播放列表。

添加 M3U 播放列表

  1. 打开添加播放列表，选择 M3U / XMLTV 卡片。
  2. 在名称字段中为列表命名（例如「主列表」）。
  3. 在URL / 文件路径字段中输入 M3U 链接，或点击文件夹图标从设备选择文件。支持的扩展名：.m3u、.m3u8、.xml、.txt。
  4. 点击添加——列表开始下载和处理；进度显示在底部下载栏中。

选择文件时，如果名称字段为空，会自动填入文件名。URL 必须以 http/https 开头。

添加 Xtream Codes 账户

  1. 选择 Xtream 卡片。
  2. 源名称：任意名称（如「主 Xtream」）。
  3. 服务器 URL：服务商地址，例如 http://server.com:8080
  4. 用户名和密码：来自服务商的凭据。密码字段旁的眼睛图标可显示输入内容。
  5. 添加——应用连接 Xtream API；直播、电影和剧集分别下载。

免费版仅允许 1 个播放列表（M3U 或 Xtream——二者选一）。无限制：Pro。

添加 EPG 源（XMLTV）

要获得节目表，请添加服务商的 XMLTV/EPG 地址：

  1. 打开设置 › 电视指南 › 添加 EPG 源。
  2. 输入名称和 URL/地址并保存。
  3. 下载后频道按名称相似度自动匹配；其余通过 EPG 频道匹配手动配对。

免费版允许 1 个 EPG 源。部分 Xtream 服务商会自带 EPG——添加 Xtream 源后 EPG 通常会自动导入。

分组、排序与名称过滤

  • 频道分组：管理来自 M3U/Xtream 的分组名。隐藏的分组不会出现在电视列表中；排序决定分组顺序。
  • 排序：选「手动」可在频道列表中创建自定义顺序；「原始顺序」保持文件原样。
  • 名称过滤：去除频道名前后的模式（如国家前缀）——列表更整洁。VOD 名称有单独过滤器：设置 › 媒体信息 › VOD 名称过滤。

使用电视指南（EPG）

电视列表在两种视图间切换：频道列表和 EPG 网格（「切换到 EPG 列表」/「切换到频道列表」）。

  • 侧栏：频道台标和名称。▲▼切换频道；节目显示在另一侧。
  • 网格：时间轴——带时长的节目卡片。◀▶在时间中移动。
  • 日期选择：用昨天/今天/明天按钮和「前一天/后一天」箭头回看，最多可回溯至过往 EPG 数据天数设置的值。
  • 在频道行上长按 OK：打开 EPG 上下文菜单（收藏、录制、提醒、隐藏…）。
  • 在频道上短按 OK：全屏观看。

频道没有 EPG？先检查 EPG 源已分配并更新（设置 › 电视指南 › 更新 EPG），然后通过「EPG 匹配」手动配对频道。

搜索与语音搜索

  • 搜索菜单（或上下文菜单中的「搜索」）打开智能搜索。同时搜索电影、剧集、频道名和 EPG 节目（「节目匹配」「电视节目」）。
  • 麦克风图标启动语音搜索——「正在聆听…」亮起时说话；首次会请求麦克风权限。
  • 搜索历史显示此前的查询；「清除」可删除。
  • 在移动端，搜索标签页功能相同；通过触摸输入。

多屏（PIP）

通过卡片中的 PIP 或多屏功能，可同时观看多个频道（最多 4 屏）。多屏菜单选项：

  • 添加屏幕 / 关闭屏幕：打开新的播放格或关闭所选格。
  • 均分显示 / 大屏幕：均分屏幕或放大其中一格。
  • 切换频道：更改当前焦点格的频道。
  • 全屏 / 返回多屏 / 单屏：放大某格或返回多屏视图。
  • 播放/暂停、静音/取消、重新加载：每个格的播放与音频（音频始终只来自一个屏幕）。

多屏对处理器负担较大；低配置设备建议用两屏。

录制与提醒 PRO

节目录制

  1. 在 EPG 中要录制节目的频道行上长按 OK。
  2. 录制：将节目连同设置中的附加分钟加入录制列表。若无节目，则安排从现在起的 2 小时手动录制。
  3. 自定义录制：在创建录制前打开选择首尾附加分钟（0/+1/+5/+10 分钟）的窗口。
  4. 到时间后录制自动开始；节目流中该节目卡上的 REC 图标闪烁。

设置 › 录制中的项目：

项目说明
录制文件夹录制保存位置：内部存储或网络文件夹（SMB——「扫描网络」查找资源并用用户名/密码连接）。
录制前 / 后附加时间每次录制开头和结尾附加的时间：0、1、5 或 10 分钟。节目延迟开始或超时时不会错过首尾。
录制列表全部/已完成/已排期计数及所有录制：用 OK 播放已完成项，取消待录制项，删除。

录制写入所选文件夹；请确保有足够的可用空间。支持选择 USB/SD 卡。

提醒

  • 用 EPG 上下文菜单中的添加提醒为节目创建提醒；再次选择可删除。
  • 通知时间：节目开始前 1、2、5 或 10 分钟。

故障排除与常见问题

频道不出现 / 播放列表无法加载

确认 URL 正确且以 http(s):// 开头。在设置 › 播放列表 › 现有播放列表中选择源并用「更新」重新加载；Xtream 检查用户名/密码中没有空格。同时检查网络连接和服务商是否在线。

EPG（节目表）为空

先通过设置 › 电视指南 › 添加 EPG 源添加 XMLTV 源，并点更新 EPG按钮下载。若频道仍无数据，用上下文菜单中的EPG 匹配手动选择正确的 EPG 频道。时间偏移？用时移修正。

流打不开或卡顿

在设置 › 播放器中将缓冲设为「中/大」；不行的话在视频输出中试试软件解码。4K 流对低配设备负担重——频道的 HD/FHD 版本更流畅。

没有声音或音画不同步

尝试在设置 › 播放器 › 音频输出中关闭音频透传（bitstream 在部分设备上有问题）。不同步用音频偏移滑块调整；若流中有其他语言，在播放器卡片的播放语言中选择音轨。

字幕不显示或字符乱码

在播放器卡片或设置 › 播放器 › 字幕中选择正确的字幕轨；乱码则更改编码（UTF-8…）。大小/颜色/位置在同一面板设置。

海报和电影信息不加载

检查设置 › 媒体信息中 TMDB/OMDb 密钥已输入且服务已开启（密钥免费）。用「丰富所有内容」批量拉取数据；匹配错误用内容菜单中的搜索并匹配内容修正。

购买了 Premium 但未激活 / 其他设备上看不到

确认已用同一 Google 账户登录——许可会同步。若设备数已达上限，在设置 › 账户、同步与设备中删除旧设备。必要时使用激活码。

电视长时间休眠后所有频道都打不开

完全关闭应用再重新打开。应用进入休眠时会自动关闭播放器；若仍卡住，重启可解决。

如何把设置迁移到另一台设备？

用设置 › 其他 › 备份生成文件，然后在新设备上用恢复数据导入——或登录 Google 账户使用同步。

频道找不回来 / 不在列表中

可能被隐藏了：用 EPG 上下文菜单中的显示隐藏频道或设置 › 家长控制 › 隐藏频道恢复。若被锁定——用 PIN 解锁。若分组被隐藏，检查设置 › 播放列表 › 频道分组。

如何删除账户？

设置 › 账户、同步与设备 › 删除账户可将账户连同云端数据永久删除。详见：删除账户页面。
