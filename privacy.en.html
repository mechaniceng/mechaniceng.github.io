Privacy Policy

Last updated: September 6, 2026

This privacy policy explains how Tivi Ease Go ("Application") mobile and Android TV application collects, uses, stores, and protects user data. By installing and using the Application, you agree to this policy.

1. Data We Collect

1.1. Account Information (Firebase Authentication)

The Application uses Firebase Authentication for account creation and sign-in. The following information is collected:

  • Email address — for account creation and sign-in
  • Password — hashed by Firebase, never stored in plain text
  • Display name — optional profile name

1.2. Device Identifier

For premium license verification and device management:

  • ANDROID_ID — device identifier provided by the Android system (Settings.Secure.ANDROID_ID)
  • This identifier is used to track which devices have active premium licenses
  • This identifier is not used for advertising or tracking purposes

1.3. Purchase Information (Google Play Billing)

To verify your premium purchases:

  • Purchase token — purchase verification token provided by Google Play
  • Purchase date and product ID
  • Information is obtained via Google Play Billing API and verified through Firebase Cloud Functions

1.4. IPTV / Playlist Information

To play your IPTV playlists:

  • M3U/Xtream Codes server URLs and login credentials — entered by the user
  • Channel lists and EPG (Electronic Program Guide) data — fetched from the user's IPTV server
  • This information is used solely to access the user's own IPTV service

1.5. Viewing Data (On-Device Only)

The following data is stored only on your device and is not sent to servers:

  • Watch progress — movie/series viewing position
  • Favorites / My List — marked content
  • Recordings — recording settings
  • Channel ordering and hidden channels
  • Player settings

1.6. Synchronization Data (Firebase Firestore)

When account synchronization is enabled, the following data is uploaded to Firebase Firestore:

  • Favorites, watch progress, recording settings
  • Playlist configuration
  • Profile settings

This data is tied exclusively to your account and is not shared with other users.

1.7. Metadata Queries (TMDB / OMDb)

To enrich movie and series metadata (posters, descriptions, cast):

  • Movie/series titles are queried against TMDB (themoviedb.org) and OMDb APIs
  • Poster and backdrop images are downloaded from TMDB CDN and cached on-device
  • These queries are for content enrichment purposes only

2. Data We Do Not Collect

The Application does not collect or process the following data:

  • Advertising identifiers (GAID / AAID / IDFA)
  • Personal identification numbers (national ID, passport, address)
  • Location data (GPS)
  • Contacts / address book
  • SMS or call history
  • Browser history
  • Photo gallery or camera access
  • Microphone access (except for voice search, only when initiated by the user)

4. Data Storage and Security

4.1. Local Storage (On-Device)

  • Watch progress, favorites, and settings are stored on-device using SharedPreferences
  • Posters and channel logos are cached in the temporary directory (max. 150 MB)
  • Recordings are stored in the device's storage

4.2. Cloud Storage (Firebase)

  • Authentication data is managed by Firebase Authentication
  • Synchronization data is stored in Firebase Firestore
  • Premium license information is stored in Firebase Firestore
  • All cloud communication is encrypted via HTTPS/TLS

4.3. Security Measures

  • Passwords are never stored in plain text — Firebase Authentication handles hashing
  • Root detection and APK signature verification for security checks
  • All network communication is encrypted via SSL/TLS
  • IPTV server credentials are stored locally on-device and are not shared with third parties

5. Third-Party Services

5.1. Firebase (Google LLC)

  • Purpose: Authentication, cloud synchronization, Cloud Functions
  • Data: Email, password hash, synchronization data, device identifier
  • Policy: Firebase Privacy Policy

5.2. Google Play Billing

  • Purpose: Premium purchase processing
  • Data: Purchase token, product ID
  • Policy: Google Privacy Policy

5.3. TMDB (The Movie Database)

  • Purpose: Movie/series metadata and poster provisioning
  • Data: Movie/series title queries (including IP address)
  • Policy: TMDB Privacy Policy

5.4. OMDb API

  • Purpose: Movie/series metadata provisioning
  • Data: Movie/series title queries
  • Policy: OMDb Privacy Policy

6. Children's Privacy

The Application is not directed to children under 13. We do not knowingly collect personal data from children under 13. If you become aware that a child under 13 has provided us with personal data, please contact us and we will immediately delete such data.

7. Data Deletion

The following deletion options are available within the Application:

  • Delete Account: Settings → Account → Delete Account — all your cloud data is permanently deleted
  • Sign Out: You can sign out of your account; local data remains on the device
  • Clear Cache: Settings → Storage — poster/logo cache can be cleared
  • Data Export: You can view your synchronization data from your account

All deletion requests are processed within 30 days.

8. GDPR and KVKK Compliance

Under the EU General Data Protection Regulation (GDPR) and the Turkish Personal Data Protection Law (KVKK), you have the following rights:

  • Access to your data
  • Rectification of your data
  • Erasure of your data ("right to be forgotten")
  • Restriction of processing
  • Data portability
  • Objection to processing

To exercise these rights, contact us at tivieasego@gmail.com.

9. Cookies and Advertising
