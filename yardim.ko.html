시작하기

TiviEase Go는 하나의 앱으로 Android TV와 폰/태블릿에서 모두 실행됩니다. 앱은 채널이나 콘텐츠를 제공하지 않습니다 — 사용자의 IPTV 제공업체에서 받은 M3U 재생목록 또는 Xtream Codes 계정을 추가합니다.

재생목록이 아직 설정되지 않았다면 앱을 열 때 환영 화면이 표시됩니다. 4개의 카드가 있습니다:

프로필 선택

기기에 여러 프로필이 설정되어 있으면 실행 시 «프로필 선택» 화면이 표시됩니다. 방향키 + OK로 선택합니다. PIN이 있는 프로필은 먼저 코드를 묻습니다. 각 프로필은 자체 즐겨찾기, «내 목록» 콘텐츠, 기록, 개인 설정을 유지합니다.

  • 프로필 추가/수정: 설정 › 프로필(프로필 관리 참조).
  • 사용 중 프로필 전환: 상단 바의 프로필 사진 아이콘을 누르세요.

QR 로그인 TV 모바일

TV에서 자격 증명을 입력하는 대신 폰을 사용하세요:

  1. TV에서 QR 로그인 카드를 엽니다(환영 화면 또는 설정 › 계정) — QR 코드가 나타나고 3분간 유효합니다.
  2. 폰에서 TiviEase Go 앱을 열고 스캐너로 TV의 QR 코드를 스캔합니다.
  3. 폰에서 «로그인»을 누릅니다 — «승인됨 — TV가 로그인 중입니다»라고 표시됩니다.
  4. TV가 몇 초 안에 폰의 계정으로 로그인하고; 재생목록과 설정이 동기화됩니다.

QR 코드가 만료되면 창을 닫고 다시 열면 새 코드가 생성됩니다. QR 로그인은 폰의 앱이 열려 있고 로그인되어 있어야 합니다.

Google 로그인 및 동기화

Google 계정으로 로그인하면 다음이 기기 간에 동기화됩니다: 소스/목록 설정, 즐겨찾기, «내 목록», 기록, 프로필, 프리미엄 라이선스. 첫 로그인 후 소스와 EPG가 자동으로 다운로드됩니다 — 수동 업데이트 불필요.

  • 동기화 설정 및 연결된 기기: 설정 › 계정, 동기화 & 기기.
  • 계정 없이도 사용 가능 — 데이터는 기기에 남습니다.

재생목록 추가

두 가지 소스 유형이 지원됩니다: M3U(URL 또는 로컬 파일) 및 Xtream Codes(서버 + 자격 증명). 추가하면 콘텐츠가 자동으로 라이브 / 영화 / 시리즈로 분류됩니다.

어디서 추가하나요?

  • 환영 화면의 재생목록 추가 카드에서,
  • 또는 설정 › 재생목록 › 재생목록 추가에서.

M3U 재생목록 추가

  1. 재생목록 추가를 열고 M3U / XMLTV 카드를 선택합니다.
  2. 이름 필드에 목록 이름을 지정합니다(예: «메인 목록»).
  3. URL / 파일 경로 필드에 M3U 링크를 입력하거나 또는 폴더 아이콘으로 기기에서 파일을 선택합니다. 지원 확장자: .m3u, .m3u8, .xml, .txt.
  4. 추가를 누릅니다 — 목록이 다운로드되고 처리됩니다; 진행 상황은 하단 다운로드 바에 표시됩니다.

파일을 선택할 때 이름 필드가 비어 있으면 파일 이름이 자동으로 채워집니다. URL은 http/https로 시작해야 합니다.

Xtream Codes 계정 추가

  1. Xtream 카드를 선택합니다.
  2. 소스 이름: 임의의 이름(예: «메인 Xtream»).
  3. 서버 URL: 제공업체 주소, 예: http://server.com:8080
  4. 사용자 이름 및 비밀번호: 제공업체의 자격 증명. 비밀번호 필드 옆의 눈 아이콘으로 입력 내용을 표시합니다.
  5. 추가 — 앱이 Xtream API에 연결; 라이브, 영화, 시리즈가 개별적으로 다운로드됩니다.

무료 버전은 재생목록 1개만 허용합니다(M3U 또는 Xtream — 둘 다 아님). 무제한: Pro.

설정 › 재생목록의 항목:

EPG 소스 추가(XMLTV)

프로그램 일정을 받으려면 제공업체의 XMLTV/EPG 주소를 추가하세요:

  1. 설정 › TV 가이드 › EPG 소스 추가를 엽니다.
  2. 이름과 URL/주소를 입력하고 저장합니다.
  3. 다운로드 후 채널이 이름 유사도로 자동 매칭; 나머지는 EPG 채널 매칭으로 수동 매칭합니다.

무료 버전은 EPG 소스 1개만 허용합니다. 일부 Xtream 제공업체는 자체 EPG를 보냅니다 — Xtream 소스를 추가하면 EPG가 자동으로 오는 경우가 많습니다.

그룹, 정렬 및 이름 필터

  • 채널 그룹: M3U/Xtream에서 온 그룹 이름 관리. 숨겨진 그룹은 TV 목록에 표시되지 않음; 정렬로 그룹 순서 결정.
  • 정렬: «수동»으로 채널 목록에 자체 순서 생성; «원래 순서»는 파일 순서 그대로 유지.
  • 이름 필터: 채널 이름 앞/뒤의 패턴 제거(예: 국가 접두사) — 더 깔끔한 목록. VOD 이름용 별도 필터: 설정 › 미디어 정보 › VOD 이름 필터.

TV 가이드(EPG) 사용

TV 목록은 두 보기 사이를 전환합니다: 채널 목록과 EPG 그리드(«EPG 목록으로 전환» / «채널 목록으로 전환»).

  • 옆 열: 채널 로고와 이름. ▲▼로 채널 변경; 프로그램이 반대쪽에 표시됩니다.
  • 그리드: 타임라인 — 길이가 있는 프로그램 카드. ◀▶로 시간 이동.
  • 날짜 선택: 어제 / 오늘 / 내일 버튼과 «이전 날 / 다음 날» 화살표로 지난 날짜 EPG 데이터 설정이 허용하는 만큼 과거로 볼 수 있습니다.
  • 채널 행에서 OK 길게 누르기: EPG 컨텍스트 메뉴 열기(즐겨찾기, 녹화, 리마인더, 숨기기…).
  • 채널에서 OK 짧게: 전체 화면 시청.

채널에 EPG가 없나요? 먼저 EPG 소스가 할당되고 업데이트되었는지 확인(설정 › TV 가이드 › EPG 업데이트), 그다음 «EPG 매칭»으로 채널을 수동 매칭하세요.

검색 및 음성 검색

  • 검색 메뉴(또는 컨텍스트 메뉴의 «검색»)가 스마트 검색을 엽니다. 영화, 시리즈, 채널 이름, EPG 프로그램을 동시에 검색(«프로그램 일치», «TV 프로그램»).
  • 마이크 아이콘으로 음성 검색 시작 — «듣는 중…»이 켜지면 말하세요; 처음에 마이크 권한을 묻습니다.
  • 검색 기록에 이전 쿼리 표시; «지우기»로 삭제.
  • 모바일에서는 검색 탭이 같은 역할; 입력은 탭으로.

멀티스크린(PIP)

카드의 PIP 또는 멀티스크린 기능으로 여러 채널을 동시 시청(최대 4화면). 멀티스크린 메뉴 옵션:

  • 화면 추가 / 화면 닫기: 새 재생 셀을 열거나 선택한 셀 닫기.
  • 균등 표시 / 큰 화면: 화면을 균등 분할하거나 하나를 확대.
  • 채널 변경: 포커스된 셀의 채널 변경.
  • 전체 화면 / 화면으로 돌아가기 / 단일 화면: 셀을 확대하거나 멀티 보기로 복귀.
  • 재생/일시정지, 음소거/해제, 다시 로드: 각 셀의 재생과 오디오(오디오는 항상 한 화면에서만).

멀티스크린은 프로세서에 부담; 저사양 기기에서는 2화면을 권장합니다.

문제 해결 및 자주 묻는 질문

채널이 오지 않음 / 재생목록이 로드되지 않음

URL이 올바르고 http(s)://로 시작하는지 확인하세요. 설정 › 재생목록 › 기존 재생목록에서 소스를 선택하고 «업데이트»로 다시 로드; Xtream은 사용자 이름/비밀번호에 공백이 없는지 확인. 인터넷 연결과 제공업체 온라인 여부도 확인하세요.

EPG(프로그램 일정)가 비어 있음

먼저 설정 › TV 가이드 › EPG 소스 추가로 XMLTV 소스를 추가하고 EPG 업데이트 버튼으로 다운로드하세요. 그래도 데이터가 없으면 컨텍스트 메뉴의 EPG 매칭으로 올바른 EPG 채널을 수동 선택. 시간이 어긋나나요? 시간 시프트로 수정.

스트림이 열리지 않거나 끊김

설정 › 플레이어에서 버퍼를 «중/대»로 설정; 안 되면 비디오 출력에서 소프트웨어 디코딩을 시도. 4K 스트림은 저사양 기기에 무겁습니다 — 채널의 HD/FHD 버전이 더 좋습니다.

소리가 안 나거나 오디오-영상이 어긋남

설정 › 플레이어 › 오디오 출력에서 오디오 패스스루를 꺼 보세요(bitstream은 일부 기기에서 문제). 어긋남에는 오디오 오프셋 슬라이더 사용; 스트림에 다른 언어가 있으면 플레이어 카드의 재생 언어에서 트랙 선택.

자막이 안 보이거나 글자가 깨짐

플레이어 카드 또는 설정 › 플레이어 › 자막에서 올바른 트랙 선택; 글자가 깨지면 인코딩 변경(UTF-8…). 크기/색상/위치는 같은 패널에서 설정.

포스터와 영화 정보가 오지 않음

설정 › 미디어 정보에서 TMDB/OMDb 키가 입력되고 서비스가 켜져 있는지 확인(키는 무료). «모든 콘텐츠 인리치»로 데이터 일괄 가져오기; 잘못된 매칭은 콘텐츠 메뉴의 검색 및 매칭으로 수정.

Premium을 샀는데 활성화 안 됨 / 다른 기기에 안 나타남

같은 Google 계정으로 로그인했는지 확인 — 라이선스가 동기화됩니다. 기기 한도가 찼으면 설정 › 계정, 동기화 & 기기에서 오래된 것을 삭제. 필요하면 활성화 코드 사용.

TV가 오래 절전된 후 아무 채널도 안 열림

앱을 완전히 닫고 다시 여세요. 절전 진입 시 플레이어가 자동으로 닫힙니다; 그래도 멈추면 재시작으로 해결됩니다.

설정을 다른 기기로 옮기려면?

설정 › 기타 › 백업으로 파일을 만들고 새 기기에서 데이터 복원으로 가져오기 — 또는 Google 로그인하고 동기화 사용.

채널을 되돌릴 수 없음 / 목록에 없음

숨겨졌을 수 있습니다: EPG 컨텍스트 메뉴의 숨긴 채널 표시 또는 설정 › 자녀 보호 › 숨긴 채널로 복원. 잠겼다면 PIN으로 해제. 그룹이 숨겨졌다면 설정 › 재생목록 › 채널 그룹 확인.

계정을 삭제하려면?

설정 › 계정, 동기화 & 기기 › 계정 삭제로 클라우드 데이터를 포함해 계정을 영구 삭제합니다. 자세히: 계정 삭제 페이지.
