เพิ่มเพลย์ลิสต์ของคุณ หยิบรีโมท — ที่เหลือเป็นหน้าที่ของ TiviEase Go

M3U และ Xtream Codes

เพิ่มเพลย์ลิสต์ด้วย URL ไฟล์ในเครื่อง หรือบัญชี Xtream (เซิร์ฟเวอร์ + ชื่อผู้ใช้ + รหัสผ่าน) ถ่ายทอดสด ภาพยนตร์ และซีรีส์ถูกแยกอัตโนมัติ

ตรวจจับภาษาและคำบรรยายอัตโนมัติ

ค้นหาภาษาที่คุณต้องการโดยอัตโนมัติในเนื้อหาที่มีหลายแทร็กเสียงและคำบรรยาย — แทร็กเสียงและคำบรรยายที่ถูกต้องจะถูกเลือกเองสำหรับทุกเรื่อง

ไกด์ EPG

โฟลว์รายการต่อช่องจากแหล่ง XMLTV จับคู่อัตโนมัติ/ด้วยตนเอง เลื่อนเวลา และรองรับข้อมูลวันที่ผ่านมา

บันทึกและเตือน

กดค้างที่รายการใน EPG: ตั้งเวลาบันทึกหรือสร้างการเตือน รับการแจ้งเตือนหรือให้ช่องเปิดเอง

หลายหน้าจอ (PIP)

ดูพร้อมกันสูงสุด 4 ช่อง เทียบกัน มุมมองเท่ากัน โหมดหน้าจอใหญ่ และควบคุมแยกแต่ละช่อง

โปรไฟล์และการควบคุมโดยผู้ปกครอง

ทุกคนมีโปรไฟล์ของตัวเอง: รายการโปรด ประวัติ และการตั้งค่าแยกกัน ล็อก PIN ขีดจำกัดอายุ และซ่อนช่องปกป้องเด็ก

ดาวน์โหลดและออฟไลน์

ดาวน์โหลดภาพยนตร์และตอนต่างๆ ดูโดยไม่ใช้อินเทอร์เน็ต บันทึกและดาวน์โหลดไปยังโฟลเดอร์เครือข่าย SMB

โทรศัพท์เป็นรีโมท

เปลี่ยนโทรศัพท์เป็นรีโมททีวี: ดีแพด ปุ่มตัวเลข ปุ่มสี แป้นพิมพ์ — ทั้งหมดในแอป

DLNA และการแคสต์

สตรีมไปยังอุปกรณ์ DLNA ในเครือข่าย หรือส่งเนื้อหาจากโทรศัพท์ไปยังทีวี

รองรับ TMDB และ OMDb

โปสเตอร์ คำอธิบาย นักแสดง และเรตติ้ง IMDb ด้วย API key ฟรีของคุณเอง โหลดเร็วด้วยแคชอัจฉริยะ

เปิดแอป

เมื่อเปิดครั้งแรกจะเจอหน้าต้อนรับ: เลือกการ์ด «เพิ่มเพลย์ลิสต์»

เพิ่มเพลย์ลิสต์

สำหรับ M3U ใส่ URL หรือเลือกไฟล์; สำหรับ Xtream: เซิร์ฟเวอร์ + ชื่อผู้ใช้ + รหัสผ่าน

เพิ่ม EPG

ใส่ที่อยู่ XMLTV ของคุณใน การตั้งค่า › ไกด์ทีวี › «เพิ่มแหล่ง EPG»; ช่องจะจับคู่อัตโนมัติ
