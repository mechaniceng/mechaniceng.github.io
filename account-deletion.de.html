Tivi Ease Go — Anleitung zur Kontolöschung

Sie können Ihr Tivi-Ease-Go-Konto und alle zugehörigen Daten jederzeit löschen. Nachfolgend finden Sie die verfügbaren Methoden.

Methode 1: Löschung in der App (empfohlen)

  1. Öffnen Sie die App Tivi Ease Go auf Ihrem Gerät.
  2. Navigieren Sie zu Einstellungen → Konto.
  3. Wählen Sie Konto löschen.
  4. Bestätigen Sie die Löschung, indem Sie bei Aufforderung Ihr Passwort eingeben.
  5. Ihr Konto und alle zugehörigen Cloud-Daten werden dauerhaft gelöscht.

Methode 2: Anfrage per E-Mail

Wenn Sie keinen Zugriff auf die App haben, können Sie die Kontolöschung per E-Mail beantragen:

  1. Senden Sie eine E-Mail an tivieasego@gmail.com
  2. Verwenden Sie die Betreffzeile: „Kontolöschung"
  3. Geben Sie die E-Mail-Adresse an, die mit Ihrem Tivi-Ease-Go-Konto verknüpft ist
  4. Wir bearbeiten Ihre Anfrage innerhalb von 30 Tagen

Welche Daten werden gelöscht

Wenn Sie Ihr Konto löschen, werden die folgenden Daten dauerhaft entfernt:

DatentypSpeicherortGelöscht
E-Mail und PasswortFirebase AuthenticationJa — dauerhaft
GerätekennungFirebase FirestoreJa — dauerhaft
Premium-LizenzinformationenFirebase FirestoreJa — dauerhaft
Favoriten und WiedergabefortschrittFirebase FirestoreJa — dauerhaft
ProfileinstellungenFirebase FirestoreJa — dauerhaft
Playlist-KonfigurationFirebase FirestoreJa — dauerhaft

Welche Daten bleiben erhalten

Die folgenden Daten können nach der Kontolöschung auf Ihrem Gerät verbleiben (Sie können sie manuell entfernen):

  • Lokaler Cache — Poster, Kanallogos (leeren über Einstellungen → Speicher → Cache leeren)
  • Lokale Aufnahmen — im Gerätespeicher gespeichert (manuell löschen)
  • IPTV-Server-Zugangsdaten — lokal auf dem Gerät gespeichert (über die App-Einstellungen entfernen)

Hinweis: Kaufbelege von Google Play Billing werden von Google aufbewahrt und können von uns nicht gelöscht werden. Die Verknüpfung zwischen Ihrem Kauf und Ihrem gelöschten Konto wird jedoch entfernt.

Zeitrahmen der Löschung

  • Löschung in der App: Sofort — das Konto wird gelöscht, sobald Sie die Löschung bestätigen
  • E-Mail-Anfrage: Innerhalb von 30 Tagen nach Eingang Ihrer Anfrage
